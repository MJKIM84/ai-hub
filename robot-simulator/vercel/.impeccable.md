## Design Context

### Users
사용자가 공개 포트폴리오에서 로봇 플랫폼을 직접 체험하도록 만드는 진입 화면이다. 사용자는 실제 다층 공간, 여러 로봇, 보행자와 물품 작업을 원하며, 정적인 영상이나 이동만 하는 예제에 불만을 표현했다.

### Brand Personality
기존 ROBOT LAB의 명료하고 차분한 관제 화면을 따른다. 구체적인 실행 내용과 현재 상태를 보여 주며, 검증하지 않은 성공을 강조하지 않는다.

### Aesthetic Direction
기존 밝은 배경과 파란 강조색, 한국어 안내, 실제 앱 화면을 사용한다. 별도 리브랜딩은 하지 않는다.

### Design Principles
- 주요 행동은 체험 시작 하나로 둔다.
- 시작 중, 사용 중, 만료, 수용량 초과를 명확히 구분한다.
- 체험 시간과 임시 저장의 의미를 시작 전에 설명한다.
- 실제 실행 화면을 사용하며 장식용 로봇 이미지는 만들지 않는다.
- 키보드와 작은 화면에서도 시작과 종료를 사용할 수 있게 한다.
