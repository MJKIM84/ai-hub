## 사용

로컬 확인 주소: http://127.0.0.1:5188/ (검증 서버가 실행 중일 때).
`실시간 관제 → 3D 물리`에서 **로봇 외장**으로 켜고 끈다. 로봇을 선택하면 기존 카메라 초점·따라가기를 사용한다. 물리 진단에서는 외장이 숨겨지고 원래 물리 형상이 표시된다. 라이브 배포는 하지 않았다.

구현: [RobotDesign.ts](../../../web/src/RobotDesign.ts), [PhysicsView.tsx](../../../web/src/PhysicsView.tsx).
각 외장은 실제 물리 geom의 자식으로 연결돼 차체·바퀴·팔·손가락의 위치와 회전을 그대로 따른다. 별도 동작 애니메이션이나 제어 기능을 추가하지 않았다. 물품·장비·Spot 및 미지원 사용자 모델은 기존 형상을 사용한다.

## 보조 바퀴 마감 후속 수정

같은 날 구체 그대로 노출되던 앞뒤 볼 캐스터에 고무 바퀴·금속 허브·연결 브래킷 외장을 추가했다([수정 화면](caster-finish.png)). 접촉 중심과 바퀴 최하단 높이는 기존 구형 접촉체와 같다. 브래킷은 실제 차체 방향을 사용하며 볼 조인트의 자유 회전을 따라 뒤집히지 않는다. 외장은 방향 전환이나 회전 동작을 합성하지 않는다. 차체 자세가 없거나 물리 진단을 켜면 원래 접촉체를 표시한다. 서버 물리 코드·접촉체·질량·마찰·제어기는 변경하지 않았다.

`node scripts/check-robot-design.mjs`에서 차체 기울기 및 볼 회전과 브래킷 방향 분리, 접촉 높이, 원본 불변, 진단·누락 상태 복원을 추가 확인했고 통과했다. `npm run build` 통과(1.63초). 기존 5.054초 일시 정지 상태에서 배송 로봇·AMR 외장과 진단 전환을 브라우저로 확인했다. 추가 시뮬레이션은 실행하지 않았다. 위의 기존 실행 기록과 구분한다.
