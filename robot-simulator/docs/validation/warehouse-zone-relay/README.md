# 물류 시설 · 구역별 AMR 교대

2026-09-30. 기존 단일 운반차 샘플을 입고·출고 두 운반차의 물품 교대 구성으로 확장했다. 가상 물류 시설이며 실물 로봇은 연결하지 않는다.

## 사용 방법

작업 기록 → 샘플·예제 → **물류 시설 · 구역별 AMR 교대** → 실행 준비 → 시작. 새 라이브 작업 공간에서 최신 샘플을 불러온다. 기존 저장 버전은 자동으로 바꾸지 않는다.

1. 입고 상차 팔이 1kg 상자를 AMR A에 싣는다.
2. A가 공용 작업대로 이동하면 인계 팔이 상자를 받아 작업대에 놓는다.
3. A가 입고 구역 복귀 지점에 도착·정지한 뒤 B가 접근을 시작한다.
4. B는 대기 위치에 도착한 뒤 팔·물품·공용 작업 공간을 예약한다. 정렬 접근과 정지가 관측되면 팔이 작업대의 상자를 다시 집어 B에 싣는다.
5. B가 출고 구역으로 운반하고, 출고 팔이 최종 받침에 놓는다.
6. Spot의 순찰·복귀는 물품 업무와 병렬 진행한다. 이동 보행자 3명이 운반 동선을 교차한다.

입고 x=0–8m, 공용 인계 x=8–11m, 출고 x=11–24m. 구역은 물리 벽이 아닌 로봇 그룹별 출입 제한이다. A는 출고 구역, B는 입고 구역으로 경로를 만들 수 없다. 기존 벽·선반 형상은 보존했다. 환경 편집에서 허용 로봇 그룹과 보행자 통행을 별도로 수정할 수 있다.

운영 시나리오의 B 작업 설정에서 상차 전 접근 좌표와 방향, 인계 팔, 선행 작업을 수정할 수 있다. 새로운 `carrier_loading_pose`는 샘플 좌표에 한정된 분기가 아닌 선택적 협업 실행 입력이다. 생략한 기존 협업은 기존 동작을 유지한다. 접근 중 팔을 정지시키고 자원을 예약하며 실제 거리 센서·보행자 제동·접촉 검사를 거친다. 관측된 정렬·정지 이전에는 파지나 소유권 이전을 하지 않는다. 취소하면 정지하고 복구용 예약을 유지한다.

## 검증과 수정 이력

- 구역 도입 직후 입고 로봇의 작업 후 서비스 경로가 없어 첫 작업이 대기했다. `initial-blocked.log`에 중단 전 기록을 보존했다. 입고 구역 안에 별도 서비스 충전소를 배치했다. 충전 제어나 배터리·에너지 검사 기준은 변경하지 않았다.
- 일반 이동으로 B를 팔 바로 옆까지 보내면 팔의 전체 작업 반경이 통행을 차단했다. [수정 전 물리 결과](run-2dbcc4bed4414bf4a57a6f3669f17728.json)는 242.402 시뮬레이션 초에 접근 시간 초과 및 후속 작업 실패를 기록했다. [별도 브라우저 실패](browser-blocked.json)도 같은 실패를 보존한다.
- 이를 예약된 협업 상차 접근으로 분리했다. 일반 이동은 작업 반경 밖의 대기 위치까지이며, 마지막 정렬 접근은 협업 제어와 실제 센서로 수행한다.
- 보행 공유 구역의 Y 폭을 4.6→5.2m로 명시적으로 넓혀 기존 왕복 목적지에 몸체·감속 여유를 확보했다. 보행자 수·목적지·속도·시드는 유지했다. 목표 분리거리 0.5m도 유지했다. 제한 구역의 보행 허용은 명시적인 설정으로 추가했고 기본값은 통행 금지다.
- 프런트엔드의 엄격한 프로젝트 입력 검증에도 새 필드를 연결했다. 구역별 허용 설정·상차 접근 설정을 저장하고 다시 읽을 수 있다.

긴 실행 결과는 전체 입력·소스 해시·사건·매 시뮬레이션 1초 관측을 포함한다. 자동 검사와 연구 시뮬레이션 결과는 실물 안전 검증을 의미하지 않는다.

추가 수정 전 실행 [run-82985efa64a04606bf6671b8f8dd41ac.json](run-82985efa64a04606bf6671b8f8dd41ac.json)은 B의 물품 상차까지 완료했으나 출고 이동 중 331.202초에 시간 초과했다. 보행자 우회가 아직 상차 팔의 운동 반경 안인 B에게 회전을 요구했고, 기존 협업 제어의 직선 이탈 조건이 이를 차단했다. `pedestrian_replan` 사건의 경로와 정지 좌표 (약 10.688, 2.998)m를 보존했다. 수정은 팔 반경 안에서 우회 경로를 덮어쓰지 않는 것이다. 기존 경로로 직선 이탈하되 보행자 감속·정지는 그대로 적용하고, 실제 관측상 팔 반경 밖으로 나온 뒤 우회를 허용한다. 안전거리나 물품 성공 기준을 낮추지 않았다.
