# 25. 작업 배정 — MRTA — 보완 조사

## 요약
- LTAA 원문의 서로 다른 비교 조건을 확인해 기존 성능 충돌을 부분 해소한다.
- Open-RMF 입찰 메시지에서 플릿이 공개하는 비용·예상 로봇·완료 시각을 확인한다.
- 2024년 SMT, 2025년 MRTA-RM, 2026년 최소 비용 흐름 기반 배정을 추가한다.
- 실제 창고 실측, 계산 실험, 병원 모사 환경을 구분하고 전역 최적성의 적용 범위를 좁힌다.
- 2026-09-26 플릿 이름 필터 관련 수정 이력을 반영한다.

## 보완 항목

### 6. 대표 접근법과 기술 — 수정
- 대상 문장(수정·교차 확인일 때): "이동로봇 플릿 작업 배정 연구를 알고리즘 계열별로 정리한 문헌 검토가 있으나(2025-01), 검토 편수·계열 구분·실험 플릿 규모에 관한 수치는 이 위키에서 확인하지 못했다(미확인)."
- 새 내용: Meseguer Valenzuela·Blanes Noguera의 2025년 검토는 다중 로봇 작업 배정(Multi-Robot Task Allocation, MRTA) 방법을 휴리스틱, 메타휴리스틱, 정확·수리 휴리스틱, 시장 기반, 인공지능 기반의 다섯 계열로 정리한다. [사실][^n1] 표 I–V는 각 연구의 중앙·분산 구조, 구현 환경, 플릿 규모, 보고 결과를 함께 제시한다. [사실][^n1] 다만 본문의 휴리스틱 실험 규모 설명과 표 I의 일부 값이 달라, 전체 최대 규모나 우열을 하나의 수치로 요약하지 않는 편이 좋다. [의견][^n1]
- 근거 메모: PDF §II의 A–E 소절 및 §III 표 I–V. 본문은 최대 25대라고 설명하지만 표 I의 L. Li 외 행은 최대 45 AMR를 적는다. 1,923은 이동 랙 수이지 로봇 수가 아니다. 표 I 페이지를 렌더해 확인했다. 총 검토 편수는 선정·제외 절차가 확인되지 않아 새 수치로 제시하지 않는다.

### 6. 대표 접근법과 기술 — 수정
- 대상 문장(수정·교차 확인일 때): "LTAA(2025-12 프리프린트)는 LangGraph 기반 LLM 배정 에이전트로 단계 적응 배정·다단계 검증·계층적 재시도를 두고 건설 로봇 시나리오에서 동적 계획법·강화학습과 비교했으며, 비교 결과는 출처가 엇갈려 11절에 둔다."
- 새 내용: LTAA 원문 그림 15는 전체 성공률을 LTAA 75.97%, Q-learning 73%, DQN 77%로 보고한다. [사실][^n2] 같은 원문의 p.61은 동적 계획법(Dynamic Programming, DP)의 성공률을 95%로 적되, 결정적 알고리즘은 불확실성을 모델링하지 않아 비교 그림에서 제외했다고 설명한다. [사실][^n2] 따라서 “LTAA가 전통 배정법 전체보다 우수하다”는 결론은 지지되지 않으며, Heavy Excels 설정의 77.1%와 전체 비교 결과를 분리해 적어야 한다. [의견][^n2]
- 근거 메모: 6절 분리 페이지의 LTAA 문장. PDF pp.57–59 그림 15·16과 p.61 본문·그림 19, p.62 결론을 확인했다. p.61은 이미지로도 확인했다. 초록의 포괄적 우위 표현과 본문의 비교 제외 설명이 일치하지 않는 부분은 남아 있다. 성공률은 논문의 실험·모델 보고값이며 건설 현장 실측 완료율로 바꾸지 않는다.

### 7. 관련 표준·프레임워크·오픈소스 — 추가
- 새 내용: Open-RMF의 입찰 제안(BidProposal)은 플릿 이름, 예상 수행 로봇 이름, 새 작업 수용 전·후의 전체 배정 비용, 새 작업의 예상 완료 시각을 담는다. [사실][^n3] 이는 두 수준 배정에서 공개되는 비용·상태 정보의 구체적인 예지만, 이 메시지만으로 모든 플릿을 합친 최적 배정이 보장되지는 않는다. [추정][^n3][^n4]
- 근거 메모: BidProposal.msg의 `fleet_name`, `expected_robot_name`, `prev_cost`, `new_cost`, `finish_time` 전체 필드. rmf_task README는 계획기의 대상 집합을 한 플릿의 로봇·작업으로 설명한다. 두 문서는 같은 Open-RMF 계열이므로 독립 출처 두 개로 간주하지 않는다.

### 6. 대표 접근법과 기술 — 추가
- 새 내용: Open-RMF 작업 계획기(TaskPlanner)의 최적 배정 설명은 물리·운동 특성을 공유하는 한 플릿의 주어진 작업 집합을 대상으로 한다. [사실][^n4] 앞으로 들어올 모든 작업, 서로 다른 제조사의 내부 결정, 실제 혼잡까지 포함한 운영 전체의 전역 최적성으로 확대해서는 안 된다. [의견][^n4][^n8]
- 근거 메모: rmf_task README의 TaskPlanner 설명과 2026년 흐름 기반 배정 논문 §3.2·§5. 후자는 단순 이동 비용과 실제 혼잡 비용의 차이를 명시하고, 배정 단계의 최적 매칭과 온라인 운영 성과를 구분한다. Open-RMF와 별도 연구팀의 자료를 대조한 범위 한정이다.

### 6. 대표 접근법과 기술 — 추가
- 새 내용: Tuck 외의 2024년 연구는 이론 모듈로 만족 가능성(Satisfiability Modulo Theories, SMT)을 이용해 온라인으로 도착하는 작업의 배정·적재 용량·마감 준수를 함께 제약식으로 표현한다. [사실][^n5] 이 방법의 목표는 주어진 모델에서 제약을 만족하는 계획을 찾는 것이며, 최소 이동 비용의 전역 최적해를 찾는 것과는 구별된다. [사실][^n5] 납기 준수가 필수인 작업은 높은 우선순위 점수만 주는 방식과 별도로 검토할 필요가 있다. [의견][^n5]
- 근거 메모: 원문 §2 마지막 문단, §3.2–3.3, Definition 6의 마감 조건, §4–5. 건전성·완전성 주장은 논문의 모델과 인코딩 조건 안에서만 유효하다. 로컬 충돌 회피와 실제 이동 불확실성까지 보장하는 결과는 아니다.

### 5. 적용 사례 (현장 유형 명시) — 추가
- 새 내용: 현장 유형은 병원 모사 환경이며, Tuck 외는 병원과 유사한 공간을 그래프로 추상화한 배송 벤치마크에서 용량이 제한된 로봇의 동적 작업 배정을 평가했다. [사실][^n5] 요청의 출발·도착 위치와 발생·마감 시각을 입력하고, 새 요청이 들어올 때 이미 실행한 동작과 현재 동작을 유지한 채 계획을 갱신한다. [사실][^n5] 이는 병원 배송의 계산 실험 사례이며 병원 현장 실증으로 분류하지 않는다. [의견][^n5]
- 근거 메모: §3 Definition 9, §6 Experimental Analysis 및 벤치마크 환경. 운영 중 도착하는 작업과 용량·시간 제약을 함께 다룬다는 점을 기존 창고 가상 시나리오에 보충한다.

### 8. 대표 연구와 자료 — 추가
- 새 내용: Lee·Sim·Nam의 MRTA-RM은 장애물이 밀집하고 통로가 좁은 환경에서 로봇을 구역 사이에 재분배한 뒤 작업을 배정한다. [사실][^n6] 저자들은 수백 대 규모의 동적 시뮬레이션을 보고하고 구현을 공개했지만, 결론에서 성공률 100%와 이종 로봇 확장을 후속 과제로 남겼다. [사실][^n6][^n7] 따라서 이 연구는 혼잡을 줄이는 배정의 재현 후보이며, 임의 환경에서 교착이 없다는 보장으로 소개해서는 안 된다. [의견][^n6]
- 근거 메모: 2025년 원문 방법·실험 절과 Conclusions; 공개 저장소 README의 구역별 배정·재분배 구조, Python 실행 안내. 논문과 코드는 같은 팀의 산출물이므로 독립 재현 근거가 아니다.

### 8. 대표 연구와 자료 — 추가
- 새 내용: Zhang 외의 AAMAS 2026 연구는 환경 그래프 위의 최소 비용 흐름(Minimum-Cost Flow)으로 배정을 풀어 로봇·작업 사이 모든 쌍의 거리 행렬 계산을 피한다. [사실][^n8] 논문은 격자 벤치마크에서 최대 20,000 에이전트와 30,000 작업을 다루고, 계획기로부터 받은 혼잡 추정치를 배정 비용에 반영한다. [사실][^n8] 이 결과와 MRTA-RM을 함께 보면 배정 비용에 환경 구조와 혼잡을 반영하는 연구 흐름은 확인되지만, 두 방법의 성능 수치를 같은 조건의 순위로 비교할 수는 없다. [추정][^n6][^n8]
- 근거 메모: AAMAS 공식 논문 §2 문제 정의, §5 흐름 정식화·혼잡 비용·계획기 결합, §6 실험과 표 1. 1초 계획 예산의 격자 계산 실험이지 20,000대 실제 로봇의 실측 배치가 아니다. 단일 시점 배정의 최적성과 장기 처리량 최적성을 구분한다.

### 7. 관련 표준·프레임워크·오픈소스 — 추가
- 새 내용: `rmf_fleet_adapter` 2.14.0의 2026-09-26 변경 이력은 요청의 플릿 이름이 문자열 또는 배열에 포함되면 입찰하도록 한 수정 #534를 기록한다. [사실][^n9] 후보 플릿 제한을 사용하는 배정 사례에는 해당 수정이 포함된 패키지 버전을 함께 적는 편이 좋다. [의견][^n9]
- 근거 메모: rmf_ros2 `2.14.0` 태그의 rmf_fleet_adapter/CHANGELOG.rst. 이는 기존 조사 이후의 실제 패키지 변경이며 모든 배포판에 자동 반영되었다는 뜻은 아니다.

## 답한 열린 질문
- 질문: "출처 충돌: LTAA 에 관해 한 초록 요약은 로봇 전문화가 강한 설정에서 LLM 배정의 작업 완료율이 전통 기법보다 높았다고 전하고, 다른 2차 요약은 동적 계획법의 완료율이 더 높다고 적는다." → 부분 해소: 원문에 LTAA 전체 75.97%, Heavy Excels 77.1%, DP 95%가 모두 존재하며, DP는 불확실성 모델 차이 때문에 비교 그림에서 제외되었다. [사실][^n2] 수치의 존재는 확인했으나 동일 조건의 LLM 대 DP 우열은 확정할 수 없다. [의견][^n2]
- 질문: "ROP 가 플릿 단위로 배정하고 제조사 관제가 플릿 안에서 다시 로봇을 고르는 두 수준 배정에서 전체 최적성이 얼마나 손실되며, 제조사 관제는 어떤 비용·상태 정보를 내야 하는가?" → 부분 답변: Open-RMF 입찰은 예상 로봇·수용 전후 비용·완료 시각을 제공한다. [사실][^n3] 공개 정보의 구체적인 예는 확인했지만, 임의의 이종 플릿에서 최적성 손실을 수치로 제한하는 근거는 확인 못 함이다. [추정][^n3][^n4]
- 질문: "출하 마감·납기 같은 상위 업무 제약을 배정 목적함수(완료 시각 최소화, 비용 최소화)와 결합하는 공개 설계나 창고 사례가 있는가?" → 부분 답변: SMT 연구는 마감을 필수 제약으로 결합하는 공개 수리 설계를 제공한다. [사실][^n5] 다만 병원 모사 환경의 연구이며 출하 마감을 연동한 창고 현장 사례는 확인 못 함이다. [추정][^n5]
