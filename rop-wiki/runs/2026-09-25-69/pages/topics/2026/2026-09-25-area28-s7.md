# 28. 표준·상호운용성·다사업자 거버넌스 — 관련 표준·프레임워크·오픈소스

## 1. 세 줄 요약

- 이 영역의 표준은 로봇–관제 규격, 변경 알림 규칙, 적합성 시험, 감사·서비스 관리, 국내 표준으로 나뉜다. [의견] 전체 목록은 [표준·프레임워크 목록](../../standards/index.md)에 있다.
- 이 페이지는 [28. 표준·상호운용성·다사업자 거버넌스](../../categories/g-safety-security-intelligence-and-governance/28-standards-interoperability-and-multi-vendor-governance.md) 페이지의 "관련 표준·프레임워크·오픈소스" 절이 분량 기준을 넘어 옮겨 온 것이다. 원 페이지의 검증을 거친 내용이며 새 주장은 없다.

## 2. 배경

## 3. 본문

이 영역의 표준은 로봇–관제 규격, 변경 알림 규칙, 적합성 시험, 감사·서비스 관리, 국내 표준으로 나뉜다. [의견] 전체 목록은 [표준·프레임워크 목록](../../standards/index.md)에 있다.

| 이름 | 유형 | 이 영역과의 관계 | 출처 |
|---|---|---|---|
| [VDA 5050](../../glossary/vda-5050.md) (3.0.0) | 표준 | 관제–이동로봇 책임 분리, 의미적 버전 규칙과 판 계획. 발행일은 명세 머리에 없어 미확인 | [^ref-031][^ref-634][^ref-051] |
| MassRobotics AMR 상호운용 표준 | 표준 | 다수 제조사 AMR 공존을 위한 신원·상태 보고. 판·발행일 미확인(원문 미열람) | [^ref-253] |
| [Open-RMF](../../glossary/open-rmf.md) | 오픈소스 | 플릿 어댑터와 플릿 제어 수준으로 이종 관제 통합, OSRA 거버넌스 | [^ref-004][^ref-704][^ref-639] |
| OPC Foundation 인증 프로그램 | 평가 프로그램 | 적합성 시험 도구(CTT)와 자체·독립 시험소 인증 | [^ref-705] |
| Semantic Versioning 2.0.0 | 프레임워크 | API 변경의 호환성을 판 번호로 알리는 규칙 | [^ref-635] |
| IETF RFC 9745 | 표준 | API 자원 폐기 예고 헤더 | [^ref-706] |
| IEC 62443-3-3:2013 | 표준 | 감사 대상 이벤트·타임스탬프·감사 정보 보호 | [^ref-707] |
| ISO/IEC 20000-1:2018 | 표준 | 서비스 관리 시스템과 서비스 수준 관리 | [^ref-708] |
| ISO 10218-2:2025 | 표준 | 통합자가 예견할 수 있는 위험 대상. 물류 이동로봇 플릿 적용 범위는 미확인 | [^ref-560] |
| KOROS 1148-8:2025 | 표준 | 서비스 로봇 소프트웨어 모듈 정보모델의 상호운용성 시험 절차(단체표준). 시험 항목 미확인 | [^ref-710] |
| 로봇 엘리베이터 탑승 안전 요구사항 KS(번호 미확인) | 표준 | 로봇–승강기 연동의 안전 요구 | [^ref-709] |

VDA 5050 3.0.0 은 주문 배정·경로 계산·교착 탐지와 해소·교통 제어를 관제 쪽, 위치 추정·경로와 동작 실행·상태의 지속 전송을 이동로봇 쪽 책임으로 나눈다. [사실][^ref-031] 곧 관제가 교착 탐지·해소 기능을 맡는다. [사실][^ref-031] 그러나 교통 조율 알고리즘(교통 관리 로직) 자체와 기능·운영·시스템 안전 요구는 VDA 5050 범위 밖이라고 명시한다. [사실][^ref-031] 공식 저장소 main 브랜치 명세는 3.0.0 판이며 문서 머리에 발행일이 적혀 있지 않아, 발행일 충돌은 명세 원문으로 해소되지 않는다(확인일 2026-09-25). [사실][^ref-031]

MassRobotics AMR 상호운용 표준은 여러 제조사의 AMR 이 같은 현장에서 공존하도록 로봇의 위치·속도·방향·상태(health)·작업 가용성 정보를 공유하게 하는 것을 목적으로 한다. [사실][^ref-253] JSON 스키마는 [신원 보고(identityReport)](../../glossary/identity-report.md)와 상태 보고(statusReport) 두 보고 메시지만 정의하고 명령·작업 배정 메시지는 두지 않는다(확인일 2026-09-25). [사실][^ref-253]

Open-RMF 는 오픈소스 로보틱스 연합(Open Source Robotics Alliance, OSRA) 체계에서 프로젝트 관리 위원회(PMC)가 일상 운영을 맡고 기술 거버넌스 위원회(TGC)가 PMC 활동을 감독하는 것으로 보인다. 문서 개정 경로는 TGC 문서는 TGC 승인·OSRF 이사회 비준, 저장소 목록·작업반 헌장은 해당 PMC 비준으로 나뉜다. [추정][^ref-704][^ref-639]

한국지능형로봇표준포럼(KOROS)은 단체표준 KOROS 1148-8:2025 ‘서비스 로봇을 위한 모듈 — 제2-8부: 소프트웨어 모듈용 정보모델 상호운용성 시험 절차’를 제·개정 현황에 올렸다(기준일 2025-06-04, KOROS 게시일, 원문 미열람). [사실][^ref-710] 산업통상자원부 국가기술표준원은 2021-11-11 행정안전부(승강기 안전기준 소관)와 협력해 로봇의 엘리베이터 탑승 시 안전 요구사항과 실내 배송 로봇 등에 관한 국가표준(KS)을 제정한다고 밝혔다. [사실][^ref-709]
