# 23. 업무 시스템 연동 — 관련 표준·프레임워크·오픈소스

## 1. 세 줄 요약

- 이번 조사에서 확인한 관련 규격은 로봇 쪽 VDA 5050 3.0.0·Open-RMF 작업 API, 상위 쪽 B2MML·OPC UA for ISA-95 Job Control·ISA-95 Part 1, 업무 범위 쪽 SCOR DS 이다. [사실][^ref-031][^ref-129] 전체 목록은 [표준·프레임워크 목록](../../standards/index.md)에 있다.
- 이 페이지는 [23. 업무 시스템 연동](../../categories/integration/business-system-integration.md) 페이지의 "관련 표준·프레임워크·오픈소스" 절이 분량 기준을 넘어 옮겨 온 것이다. 원 페이지의 검증을 거친 내용이며 새 주장은 없다.

## 2. 배경

[23. 업무 시스템 연동](../../categories/integration/business-system-integration.md) 페이지를 쓰는 과정에서 "관련 표준·프레임워크·오픈소스" 절의 분량이 세부영역 페이지 기준(4,000자)을 넘어, 내용을 줄이지 않고 이 주제 페이지로 분리했다.

## 3. 본문

이번 조사에서 확인한 관련 규격은 로봇 쪽 VDA 5050 3.0.0·Open-RMF 작업 API, 상위 쪽 B2MML·OPC UA for ISA-95 Job Control·ISA-95 Part 1, 업무 범위 쪽 SCOR DS 이다. [사실][^ref-031][^ref-129] 전체 목록은 [표준·프레임워크 목록](../../standards/index.md)에 있다.


### 2026-10-11 보탠 항목

| 이름 | 유형 | 이 영역과의 관계 | 출처 |
|---|---|---|---|
| OPC UA for ISA-95 Part 4: Job Control (OPC 10031-4) 2.00.0 | 표준 | 시작 전 작업 지시만 Update(정보 전부 교체)·Cancel(기록 제거)로 바꾸고, 시작된 작업 지시는 Stop(Ended)·Abort(Aborted)로 끝낸다. 2.0 은 1.0 과 호환되지 않고 새 namespace 를 정의한다. 2024-01-31 판, 원문 대조 2026-10-11 | [사실][^ref-131] |
| Open-RMF rmf_api_msgs 응답 스키마(dispatch_task_response·cancel_task_response·simple_response) | 오픈소스 | 배정 응답은 성공 시 작업 상태를 담고, 취소 응답은 성패와 오류만 담는다 | [사실][^ref-1453][^ref-1454][^ref-1455] |
| SAP Warehouse Robotics FMS 연동 API(폐기) | 프레임워크(벤더 문서) | SAP BTP 기반 SAP Warehouse Robotics 와 제조사 관제를 잇는 API. 2024-07-10 판에서 Deprecated 로 표시되어 현재 권장 계약이 아니다 | [사실][^ref-1456][^ref-1458] |
| SAP Warehouse Robotics integration services 경로(판 2308) | 프레임워크(벤더 문서) | FMS 연동 API 와 다른 연동 경로. 최적화 미사용 시 큐 순서와 LSD·생성 시각 정렬 규칙을 설명한다 | [사실][^ref-1458] |
| Oracle WMS Cloud 26c Change Task Priority API | 프레임워크(벤더 문서) | Ready·Held·Created 상태 작업만, 권한이 켜진 경우에만 우선순위를 바꾼다 | [사실][^ref-1457] |
| NVIDIA Isaac Mission Dispatch(MCP 2026-03, VDA5050 3.0 지원 2026-08) | 오픈소스 | MCP 도구는 조회·등록·좌표 이동이며 취소 도구가 없다 | [사실][^ref-1341] |
| SAP 참조구조 Warehouse Pick & Place with Embodied AI Robotics(2026-05-12 갱신) | 프레임워크(벤더 문서) | 업무 객체의 의미 이해를 Embodied AI agents 의 주요 skill 로 둔다 | [사실][^ref-1461] |

OPC Job Control 행은 [채팅 기반 구성·운영](../../tracks/chat-based-configuration-and-operation/index.md) 트랙의 반영 제안(2026-09-25 단계 3) 가운데 Update·Abort 서술을 이번 원문 대조 결과로 반영한 것이다.
