# 23. 업무 시스템 연동 — 다른 연구영역과의 연결

<!-- auto:page-status:end -->

## 1. 세 줄 요약

- [24. 작업·워크플로 모델링](../../categories/planning-and-optimization/task-and-workflow-modeling.md) — ISA-95 작업 지시와 Open-RMF 작업 상태를 업무 단계와 잇는 문제를 함께 다루며, 같은 출처(작업 상태 스키마, task_new)를 공유한다.

## 2. 배경

[23. 업무 시스템 연동](../../categories/integration/business-system-integration.md) 페이지를 쓰는 과정에서 "다른 연구영역과의 연결 (번호와 이름을 함께 표기)" 절의 분량이 세부영역 페이지 기준(4,000자)을 넘어, 내용을 줄이지 않고 이 주제 페이지로 분리했다.

## 3. 본문

- [24. 작업·워크플로 모델링](../../categories/planning-and-optimization/task-and-workflow-modeling.md) — ISA-95 작업 지시와 Open-RMF 작업 상태를 업무 단계와 잇는 문제를 함께 다루며, 같은 출처(작업 상태 스키마, task_new)를 공유한다.
- [20. 로봇·제조사 관제 연동](../../categories/integration/robot-and-vendor-fleet-manager-integration.md) — VDA 5050 주문 갱신·취소와 Open-RMF 작업 요청은 제조사 관제와의 인터페이스 자체이며, 취소 응답과 작업 상태 관측을 나누는 Open-RMF 응답 스키마도 그 일부다.
- [29. 명령·작업 실행의 신뢰성](../../categories/execution-collaboration-and-recovery/command-and-task-execution-reliability.md) — 새 주문 거부(OTHER_ORDER_ACTIVE)와 취소·중단·되감기 요청의 처리 결과 확인이 실행 신뢰성과 이어진다.
- [25. 작업 배정 — MRTA](../../categories/planning-and-optimization/task-allocation-mrta.md) — 가장 적합한 플릿에 작업을 맡기는 요청 방식과 AMR 가용성에 따른 개입 전략이 배정 문제와 겹친다.
- [26. 작업 순서·스케줄링](../../categories/planning-and-optimization/task-sequencing-and-scheduling.md) — 출고 우선순위 변경에 따른 대기열 재정렬과 동적 재최적화가 순서 결정 문제이며, SAP Warehouse Robotics integration services 의 큐·LSD 정렬과 Lorenz 외 재최적화의 적용 조건(단일 피커·빈 로봇 즉시 가용)도 이 영역과 잇는다.
- [32. 예외 복구·재계획·업무 연속성](../../categories/execution-collaboration-and-recovery/exception-recovery-replanning-and-business-continuity.md) — 적재 후 취소의 되돌림 작업과 취소 불가 동작 처리가 복구·재계획 과제다.
- [21. 상호운용 표준·적합성](../../categories/integration/interoperability-standards-and-conformance.md) — ISA-95 계열과 로봇 인터페이스 사이 표준 매핑이 확인되지 않은 점과, Job Control 2.0 이 1.0 과 호환되지 않는 점이 상호운용성 과제와 이어진다.
- [22. 설비·건물 시스템 연동](../../categories/integration/facility-and-building-system-integration.md) — 제조 공장 사례의 WCS·SCADA 를 통한 설비 제어는 이 영역 쪽에서 다루는 연계 대상이다.
- [38. 모니터링·이상 탐지·원인 분석](../../categories/field-operations-and-monitoring/monitoring-anomaly-detection-and-root-cause-analysis.md) — SCADA 기반 통합 관제는 모니터링 쪽 기능이다.
- [12. 채팅으로 업무 지시·오케스트레이션](../../categories/chat-based-configuration-and-operation/chat-task-instruction-and-orchestration.md) — MCP 도구 범위를 업무 요청 접점으로 쓸 때의 한계와, 사람이 승인한 계획만 실행하는 대화형 지시의 원칙을 함께 본다(oq-141). 짝이 되는 엔진은 위의 25. 작업 배정 — MRTA 와 26. 작업 순서·스케줄링이다.
- [44. 로봇 기반 모델·언어 모델 계획](../../categories/ai-and-learning/robot-foundation-models-and-llm-planning.md) — Embodied AI 휴머노이드가 업무 문맥을 받아 작업을 수행하는 부분은 이 영역이 다룬다.
- [30. 로봇 간 협업·물리적 인계](../../categories/execution-collaboration-and-recovery/robot-to-robot-collaboration-and-physical-handover.md) — 인제스터를 거친 인수 확인은 물리적 인계 절차와 겹친다.
- [61. 물류창고](../../categories/site-type-applications/warehouse.md) — 국내 WMS–로봇 연동 실증 발표와 그 결과 공개 여부가 물류창고 현장의 질문이다.
- [62. 제조 공장](../../categories/site-type-applications/manufacturing-plant.md) — 신공장 물류를 WCS 로 조율한 공급자 사례가 있다.
- [63. 병원·의료](../../categories/site-type-applications/hospital-and-healthcare.md) — 시료 운반의 인수 확인 후 복귀 절차가 병원 현장의 완료·인계 예다.
