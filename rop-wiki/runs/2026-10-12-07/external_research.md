# 45. 문서·도면·장면 이해 — 보완 조사

## 요약

- 도면 점수에 입력 형식·제외 객체·평가 분모를 붙이는 보완안이다. 면적 추정 논문의 내부 단위 충돌은 미확인으로 남긴다. [의견]
- 문서 근거 위치의 누락과 URDF 기능 의미 오류를 등록 검토 단계에서 따로 표시하도록 제안한다. [의견]
- 장면 그래프 실증의 로봇 대수·전송 단위·재위치 기준과 CCTV 시험의 개입을 기존 사례에 함께 제시하도록 제안한다. [의견]
- 공사장 지도 정합·센서 동기화·국내 OCR 자료의 조건을 보완한다. 기존 도면 자동 인식/기능 온톨로지 트랙의 전체 설계는 재작성하지 않는다. [의견]

조사 범위: 고정 위키 커밋 `85960d24460c35487930df65b7f5955603645fd3`의 영역 본문과7개 절 분리 문서. 배포 웹 접근 실패로 해당 커밋과 배포본의 동일성은 확인하지 못했다. 트랙은 연결 개요만 대조했고 모든 하위 문서를 검토했다고 주장하지 않는다. 완료한 다른12영역의 결과파일은 변경하지 않았다.
