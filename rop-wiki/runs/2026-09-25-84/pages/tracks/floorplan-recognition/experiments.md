# 실험

이 페이지는 중점 연구 트랙 [건축 도면 자동 인식](index.md)에서 스토리텔러 에이전트가 제안한 실험 계획과, 사용자가 직접 수행해 저장소의 `experiments/` 폴더에 넣은 실험 결과의 요약을 모은다. 선택 페이지이며, 실험이 없어도 트랙은 진행된다.

## 실험 규칙

- 실험은 사용자가 직접 수행한다. 에이전트는 계획을 제안하고, 사용자가 넣은 결과를 읽어 반영한다.
- 이 트랙에서 계획은 단계 3·5에서 제안한다(트랙 정의의 `stage_artifacts`). [가정]
- 결과는 `experiments/<날짜>-<이름>/`에 넣고 `README.md` 머리에 트랙(`floorplan-recognition`), 단계, 답하려는 질문 id를 적는다. 다음 트랙 실행에서 `[사용자 실험]` 태그로 반영되며, `[사실]`로 올라가려면 내용 검증 에이전트의 판정이 필요하다.
- 계획 형식(계획 번호 `E<단계>-<두 자리>`, 목적, 방법, 측정 지표와 조건, 필요한 자료, 제안한 실행 id, 상태)과 결과 입력 형식은 첫 트랙의 [실험](../manual-capability-ontology/experiments.md) 페이지와 [기여·정정 방법](../../about/how-to-contribute.md)을 따른다.

## 제안된 실험 계획

아래 계획은 [단계 5. 검증 방법과 가설 판정](stage-5-verification-and-hypotheses.md#q5-03)의 q5-03 답(실행 2026-09-25-84)에서 도출했다. 가설 판정을 미판정·부분 지지에서 옮기려면 물류 조건의 직접 근거, 곧 관련 환경에서의 검증·시연이 필요하다는 논리에 기댄 이 위키의 제안이다. [추정][^ref-809][^ref-807] 수치 목표·합격 임계값·참가자 수는 근거가 없어 정하지 않았고, 후속 질문 q5-09·q5-12 에서 다룬다.

### E5-01 물류 도면 인식 지표 실험 (가설 1)

- 목적: 물류센터 도면에서 벽·문·엘리베이터·계단·충전 위치를 얼마나 인식하는지 재서 가설 1 의 핵심 하위 주장에 직접 근거를 만든다.
- 방법: 사용자가 가진 물류센터 도면(래스터·CAD·BIM 가운데 가능한 것)에 인식을 적용하고 사람이 만든 정답과 비교한다.
- 측정 지표와 조건: [q5-01](stage-5-verification-and-hypotheses.md#q5-01) 의 세 층 지표(요소 인식, 구조·그래프, 지도·정렬). 임계값은 정하지 않았다(q5-09).
- 필요한 자료: 물류센터 도면, 요소 정답 주석, 가능하면 기준 지도.
- 제안한 실행 id: 2026-09-25-84
- 상태: 제안

### E5-02 능력 대조 판정 대 실제 주행 비교 (가설 2, q5-05)

- 목적: 공간 그래프의 통과 조건과 로봇 능력을 대조한 통행 가능 판정이 실제 주행 결과와 맞는지 확인한다.
- 방법: 제조사가 다른 로봇별로 통행 가능 판정(문·계단·승강기 포함 경로)을 만든 뒤 시뮬레이션 또는 실기체로 같은 경로를 주행해 판정과 결과를 대조한다.
- 측정 지표와 조건: 통과 가능 판정 후 실패, 불가 판정의 과잉 제한 사례 수(q5-05).
- 필요한 자료: 로봇별 능력 값(q3-10), 문·승강기 연동 여부, 시험 경로.
- 제안한 실행 id: 2026-09-25-84
- 상태: 제안

### E5-03 두 조건 모델링 시간 비교 (가설 3, q5-12)

- 목적: 같은 층을 수작업과 '도면 자동 생성+보정' 두 조건으로 모델링해 시간 단축을 직접 잰다.
- 방법: [q5-02](stage-5-verification-and-hypotheses.md#q5-02) 의 측정 구성대로 단계별 시간, 요소 유형별 수정 횟수·편집 비용, 보정 후 결과 품질을 함께 기록한다.
- 측정 지표와 조건: 시간·수정·결과 품질의 세 축. 학습 효과·숙련도 통제와 참가자 수는 정하지 않았다(q5-12).
- 필요한 자료: 물류센터 층 도면, 편집 로그 또는 화면 기록(q5-13).
- 제안한 실행 id: 2026-09-25-84
- 상태: 제안

### E5-04 시뮬레이션 예측 대 현장 측정 비교 (가설 3, q5-06)

- 목적: 도면 기반 시뮬레이션 월드로 예측한 처리량·혼잡 지점이 현장 측정과 얼마나 맞는지 확인해 '시뮬레이션 초기값으로 쓸 수 있다'를 판정한다.
- 방법: 도면 기반 월드와 같은 기간의 현장 운영 기록을 비교한다. 운영 예측용이라면 [8. 실시간 세계 상태·데이터 일관성](../../categories/b-common-information-and-environment-model/08-real-time-world-state-and-data-consistency.md)의 현재 상태로 초기화한 조건도 함께 둔다.
- 측정 지표와 조건: 처리량·혼잡 지점의 예측 오차. 허용 오차는 정하지 않았다(q5-06).
- 필요한 자료: 도면 기반 시뮬레이션 월드, 로봇 모델, 주문 흐름, 현장 측정 기록.
- 제안한 실행 id: 2026-09-25-84
- 상태: 제안
