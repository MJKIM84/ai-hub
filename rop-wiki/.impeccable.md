# Design context

- Audience: Korean readers exploring robotics research, the wiki's sources, and how its articles are produced.
- Task: Understand each agent's responsibility and the handoff sequence without opening another page.
- Voice: Short, concrete Korean. Name actions and outputs; avoid promotional language, role metaphors, repeated explanations, and claims beyond the code.
- Visual direction: Keep the existing generated block-toy characters and MkDocs theme. Use readable inline lists and ordered steps; essential explanations must remain visible.
- Constraints: Respect the wiki's raw-HTML security checks, dark mode, keyboard navigation, and narrow screens. Separate model judgments from deterministic publishing code.
