## 근거와 공개 범위

1. 공개 근거에 따른 일반 연구, 발표 정리에서만 확인한 내용, 전사 미확인 항목을 분리한다.
2. 제공된 발표 정리 원문은 읽기만 하며 이 저장소에 저장하지 않는다. 발표자의 실명과 비공개로 보이는 현장명·수치는 일반화한다.
3. `[발표 내 확인]`은 제공된 정리에서 해당 이야기가 나왔다는 뜻이다. 실제 현장 성능이나 발표자의 신원을 독립 검증했다는 뜻이 아니다. 파일 상단의 작성일을 행사일로 바꾸지 않는다.
4. 직접 확인한 원문은 `[사실]`, 근거에서 유도한 추론은 `[추정]`, 적용 권고는 `[의견]`으로 표시한다. 벤더 단독 근거는 `[추정] 벤더 주장:`으로 표시한다.
5. 공개 근거를 발견하지 못했거나 원문을 열지 못한 내용은 존재하지 않는다고 단정하지 않는다. 보편적 지연 허용치·마찰계수·비용·안전 임계값을 임의로 만들지 않는다.
6. 시뮬레이터 지원 여부는 기준 커밋의 코드 위치로 한정한다. 코드 읽음은 실행·성능 검증이 아니며, 사건 주입과 실패 원인의 물리·광학·통신 재현을 분리한다.
