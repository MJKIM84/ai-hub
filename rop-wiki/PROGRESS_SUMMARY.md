## 8. 검토가 필요한 항목

1. **세부영역 분량 기준 4,000자** — 규칙대로 내용을 줄이지 않고 옮겼더니 영역마다 평균 5개 절이 주제 페이지로 갔다. 영역 페이지는 각 절의 앞 문장과 링크가 남는다. 기준을 올리거나(`settings.area_body_char_limit`) 분리 대상 절을 좁히는 것을 검토.
2. **트랙 단계 전환** — 검증 에이전트가 완료 조건 충족을 한 번도 승인하지 않아 세 트랙 모두 단계 1 이다. 단계 페이지 본문은 채워져 있다. 완료 조건 판정 기준을 정하거나 수동 전환을 결정.
3. **교차 확인 20건** — 일반 웹이 막혀 독립 출처 2개를 모두 여는 경우가 드물다. 열람이 되는 환경에서 월간 재검증을 돌리면 오른다.
4. **트랙 실행 비용 $21~35** — 트랙 페이지가 커질수록 입력이 커진다. 입력 요약을 더 하거나 트랙 주 1회로 줄이는 것을 검토.
5. **용어집 draft 10개, 참고문헌 seed 10개** — 구축 시드. 해당 용어를 쓰는 영역의 갱신 실행에 포함하면 검증을 거친다.
6. **커밋 437개** — 실행 커밋과 중간 기록이 대부분. PR 전에 정리할지 결정.
