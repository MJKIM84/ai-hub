## 3. 본문

이동로봇 플릿 작업 배정 연구를 알고리즘 계열별로 정리한 문헌 검토가 있으나(2025-01), 검토 편수·계열 구분·실험 플릿 규모에 관한 수치는 이 위키에서 확인하지 못했다(미확인). [추정][^ref-152] 아래는 여섯 갈래(중앙 최적화, 시장 기반 경매·분산 합의, 최근접 규칙, 학습 기반 배차, LLM 기반 배정, 배터리·충전 결합)로 정리한 것이다.

### 중앙 최적화

단일 작업·단일 로봇·즉시 배정 문제는 최적 배정 문제로 풀 수 있어 중앙에서 다항 시간에 최적해를 얻는다. [사실][^ref-393] 작업 사이에 선후 제약 같은 의존이 있으면 문제 범주가 달라지고 대응하는 조합 최적화·운영과학 모델도 달라진다. [사실][^ref-394] 원 페이지 [13. 작업 배정 — MRTA](../../categories/d-planning-and-optimization/13-task-allocation-mrta.md) 3절의 작업장 사례 연구도 앞으로의 요청을 함께 보는 조합 최적화 배차에 해당한다. [사실][^ref-400]

### 시장 기반 경매와 분산 합의

시장 기반 조율은 로봇들이 작업을 경매·입찰로 나누는 방식으로, 탐사·지도 작성·로봇 축구 등 여러 응용에 걸친 연구가 서베이로 정리되어 있다(2006-07). [사실][^ref-396] 합의 기반 경매 알고리즘(CBAA)과 다중 배정용 합의 기반 번들 알고리즘(Consensus-Based Bundle Algorithm, CBBA)은 국소 통신 합의로 낙찰 충돌을 풀며, 점수 체계 가정 아래 충돌 없는 배정으로 수렴하고 로봇 간 상황 인식 불일치와 통신망 변화에 강건하다고 저자들이 증명·보고했다(2009). [사실][^ref-395] 중앙 서버 없이 동작하는 대신 수렴 보장이 점수 체계 가정에 기댄다. [사실][^ref-395]

### 최근접 규칙

[다중 에이전트 픽업·배송(MAPD)](../../glossary/multi-agent-pickup-and-delivery.md)의 토큰 패싱(Token Passing, TP)에서는 토큰을 받은 에이전트가 가까운 미배정 작업을 스스로 맡는다. [사실][^ref-006] 국내 자동물류센터 설계 연구(저자·발행연도 미확인, 시뮬레이션 설계 연구)도 빈 AGV 가 가장 가까운 화물을 회수하는 최근접 규칙을 운영 규칙으로 두었다. [사실][^ref-402] 이런 순차 최근접 배정은 총 이동 시간이 더 짧은 배정 조합을 놓칠 수 있다. [사실][^ref-400]

### 학습 기반 배차

교차 규칙에 따라 학습 기반 배차는 [27. AI·학습·적응과 모델 운영](../../categories/g-safety-security-intelligence-and-governance/27-ai-learning-adaptation-and-model-operations.md)의 연구 방법이 이 영역에 적용된 것이다. Wang과 Gombolay의 ScheduleNet 은 시간 제약 네트워크에 로봇·근접 노드를 더한 이종 그래프로 배정·일정 정책을 학습하며, 작은 문제에서 모방 학습으로 훈련해 더 큰 미학습 문제에 일반화되었다고 저자들이 보고한다(게재 연도 미확인). [사실][^ref-399]

### 대규모 언어 모델(LLM) 기반 배정

첫째 갈래는 LLM 이 분해와 배정을 함께 맡는다. SMART-LLM(2023-09)은 프로그램 형식의 few-shot 프롬프트로 지시를 하위 작업으로 분해하고 로봇 팀을 구성한 뒤 하위 작업을 배정하며, 배정의 최적성 보장은 미확인이다. [사실][^ref-090][^ref-089] DART-LLM(2024-11 프리프린트)은 하위 작업 의존 관계를 방향 비순환 그래프(DAG)로 만들어 배정·실행한다. [사실][^ref-059] LTAA(2025-12 프리프린트)는 LangGraph 기반 LLM 배정 에이전트로 단계 적응 배정·다단계 검증·계층적 재시도를 두고 건설 로봇 시나리오에서 동적 계획법·강화학습과 비교했으며, 비교 결과는 출처가 엇갈려 11절에 둔다. [사실][^ref-168]

둘째 갈래는 LLM 이 의존 그래프나 수리 정식화를 만들고 해법기가 배정·일정을 푼다. 선형계획을 쓰는 LiP-LLM, PDDL과 정수계획을 결합한 PIP-LLM, 형식 언어로 이종 로봇 팀 일정을 정하는 FLEET, [혼합 정수 계획(MILP)](../../glossary/milp.md) 모델을 자동 구성하는 Peng 외(2025-03)가 있으며 모두 프리프린트다. [사실][^ref-166][^ref-181][^ref-242][^ref-167] 이 흐름은 LLM 이 지시 해석·정식화를, 전체 최적 배정은 해법기가 맡는 분담을 제안하지만, 창고 물류 조건에서 LLM 배정·해법기 배정·최근접 규칙을 비교한 연구는 이번 조사에서 확인되지 않았다. [추정][^ref-166][^ref-181][^ref-167][^ref-090]

### 배터리·충전과 배정의 결합

Open-RMF 의 rmf_task 작업 계획기(TaskPlanner)는 요청된 시작 시각을 고려해 작업이 가장 짧은 시간에 끝나도록 배정과 순서를 정하고, 배터리 제약에 따라 필요하면 충전 작업을 로봇 일정에 자동으로 끼워 넣는다. [사실][^ref-404][^ref-376] 2026-03 프리프린트는 AMR 플릿의 작업 배정과 충전 결정(충전 방식·공용 충전기 접근)을 함께 최적화하는 틀을 제안한다. [사실][^ref-403] 배터리 열화 모델 자체는 [16. 공용 자원·충전·에너지 최적화](../../categories/d-planning-and-optimization/16-shared-resource-charging-and-energy-optimization.md)에서 다룬다.
