# 6. 지도·공간·위치 모델 — 관련 표준·프레임워크·오픈소스

> 페이지 상태: published · 신뢰도: medium · 페이지 버전: 1 · 마지막 갱신: 2026-09-25 · 마지막 실행: 2026-09-25

## 1. 세 줄 요약

- 위치·지도·좌표계를 표현하는 방식은 로봇 인터페이스 규격마다 다르고, 실내 공간 표준(IFC·IndoorGML·ISO 19164)과 업무 위치 식별자(GS1 GLN)는 각각 따로 정의돼 있다. [사실][^ref-031][^ref-154][^ref-230][^ref-156][^ref-157][^ref-162]
- 이 페이지는 [6. 지도·공간·위치 모델](../../categories/b-common-information-and-environment-model/06-map-space-and-location-model.md) 페이지의 "관련 표준·프레임워크·오픈소스" 절이 분량 기준을 넘어 옮겨 온 것이다. 원 페이지의 검증을 거친 내용이며 새 주장은 없다.

## 2. 배경

[6. 지도·공간·위치 모델](../../categories/b-common-information-and-environment-model/06-map-space-and-location-model.md) 페이지를 쓰는 과정에서 "관련 표준·프레임워크·오픈소스" 절의 분량이 세부영역 페이지 기준(4,000자)을 넘어, 내용을 줄이지 않고 이 주제 페이지로 분리했다.

## 3. 본문

위치·지도·좌표계를 표현하는 방식은 로봇 인터페이스 규격마다 다르고, 실내 공간 표준(IFC·IndoorGML·ISO 19164)과 업무 위치 식별자(GS1 GLN)는 각각 따로 정의돼 있다. [사실][^ref-031][^ref-154][^ref-230][^ref-156][^ref-157][^ref-162]

| 이름 | 유형 | 이 영역과의 관계 | 원문 |
|---|---|---|---|
| [VDA 5050](../../glossary/vda-5050.md) 3.0.0 | 표준 | 위치(mapId·x·y·theta), localized·localizationScore·deviationRange, 지도 판(mapVersion·mapStatus)과 지도 배포 동작, 지도별 구역 집합을 정한다. [사실][^ref-031][^ref-051] | 열람(GitHub 원문) |
| MassRobotics AMR 상호운용 표준 스키마 | 표준 | 위치를 x·y·z·쿼터니언 각도와 planarDatum(UUID)으로 두며, 평면 기준 정의 메시지와 위치추정 신뢰도 필드는 스키마에 없다(스키마 파일 기준, 부재 확정 아님). [사실][^ref-230] | 열람(GitHub 원문) |
| [Open-RMF](../../glossary/open-rmf.md) API 로봇 상태 | 오픈소스 | 위치를 map·x·y·yaw 네 필수 필드의 2차원 위치로 보고하며 위치추정 불확실성 필드는 없다. [사실][^ref-148][^ref-154] | 열람(GitHub 원문) |
| Open-RMF traffic-editor | 오픈소스 | 평면도 배경 위에 경로·충전·대기 정점, 문·승강기·벽을 주석하고 축척·층 기준점·로봇 지도 레이어를 맞춘다. [사실][^ref-079] | 열람(GitHub 원문) |
| Open-RMF 경로 지도 요건과 [플릿 어댑터](../../glossary/fleet-adapter.md) 좌표 변환 | 오픈소스 | 경유점의 층 이름·미터 좌표·기능 속성을 요구하고, 기준 좌표 쌍으로 로봇 좌표계와 RMF 좌표계를 변환한다. [사실][^ref-080][^ref-153][^ref-105] | 열람(GitHub 원문) |
| REP 105 | 프레임워크 | ROS 이동로봇의 map·odom·earth 좌표계 의미와 연속성·드리프트 특성을 정한 규약이다. [사실][^ref-155] | 열람(GitHub 원문) |
| LIF(Layout Interchange Format) | 표준 | 무인운반차 통합사가 간선·노드·스테이션 주행 레이아웃을 제3자 중앙 관제에 넘기는 VDMA 교환 형식이며, README 기준 판은 1.0.0(2023-09)이다. [사실][^ref-046] VDA 5050 3.0.0 명세는 LIF 를 VDMA 2024-03 판으로 인용하므로 더 새 판이 있을 수 있다. [추정][^ref-031] | 열람(README) |
| ISO 21423 | 표준 | 서로 다른 공급사의 산업용 자율이동로봇(AMR) 시스템과 플릿 관리자 사이 상호운용 통신을 다루는 ISO 규격이며, 2026-09-25 검색 결과상 FDIS 단계로 나타나 최종 발행 여부는 미확인이다. [사실][^ref-159] | 미열람 |
| IFC 4.3(IfcSpace) | 표준 | 기능 공간과 건물 층의 집합 관계, 공간 바닥 높이(ElevationWithFlooring) 속성을 둔다(개발 브랜치 원본 기준). [사실][^ref-156] | 열람(GitHub 원문) |
| OGC IndoorGML 2.0 | 표준 | Part 1 개념 모델이 공개됐고 Part 2 인코딩은 작업 중이며, XML 인코딩 초안은 CellSpace·쌍대 그래프·주제 레이어·레이어 간 연결을 GML 3.2.1 로 인코딩한다. [사실][^ref-157] | 열람(초안) |
| ISO 19164:2024 | 표준 | 실내 지물의 의미 분류 체계와 속성·연관을 정하며 기하·위상 기술은 다루지 않고, IndoorGML 이 이를 구현하는 표준으로 소개된다. [사실][^ref-158] | 미열람 |
| GS1 GLN | 표준 | 물리적 위치와 하위 위치를 식별하는 업무 위치 식별자다. [사실][^ref-162] 지도 위 장소와 대응시킬 업무 쪽 키가 될 것으로 보인다. [추정][^ref-162][^ref-031] | 미열람 |

공개 평면도 데이터셋으로 CubiCasa5K(평면도 이미지 분석), MLStructFP(다세대 평면도), ResPlan(주거 평면도 1만 7천 건의 벡터·그래프), 국내 AI Hub 건축 도면 데이터가 있다(이전 실행 보고 기준, 원문 미열람). [사실][^ref-063][^ref-069][^ref-071][^ref-074] 이전 실행은 FloorPlanCAD 주석이 비상업(CC BY-NC 4.0) 조건이고 ResPlan 이 CC BY 4.0 이라고 보고했으므로, 상용 도면 인식에 쓰려면 데이터셋별 라이선스 검토가 필요할 것으로 보인다(라이선스 값은 이번 실행에서 원문으로 재확인하지 못했다). [추정][^ref-066][^ref-071]
