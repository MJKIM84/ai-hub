## 3. 본문

이 영역은 규격의 판을 어떻게 올리고 알리는지, 그리고 여러 사업자의 행위를 어떻게 기록하고 약속하는지에 관한 용어로 이루어진다. [의견]

- **의미적 버전 관리(Semantic Versioning, SemVer)** — 공개 API 선언을 요구하고, 호환되지 않는 API 변경은 MAJOR, 하위 호환 기능 추가는 MINOR, 하위 호환 버그 수정은 PATCH 를 올린다. 기능을 폐기할 때는 먼저 폐기 표시를 담은 부 버전을 낸 뒤 주 버전에서 제거하도록 권한다. [사실][^ref-635]
- **폐기 예고(Deprecation)와 종료 시각(Sunset)** — IETF RFC 9745 는 자원이 폐기되었거나 폐기될 것임을 알리는 Deprecation HTTP 응답 헤더를 정하고, RFC 8594 의 Sunset 헤더와 함께 쓰일 때 Sunset 시각은 Deprecation 시각보다 이르면 안 된다. [사실][^ref-706]
- **감사 추적(Audit Trail)** — 누가 언제 무엇을 했는지 남긴 기록이다. IEC 62443-3-3:2013 은 제어 시스템이 감사 대상 이벤트를 기록하고(SR 2.8), 감사 기록에 타임스탬프를 쓰며(SR 2.11), 감사 정보를 보호하도록(SR 3.9) 요구하고, SR 2.8 의 강화 요구로 중앙에서 관리하는 시스템 전체 감사 추적을 둔다. [사실][^ref-707]
- **서비스 수준 관리(Service Level Management)** — ISO/IEC 20000-1:2018 은 서비스 관리 시스템의 수립·실행·유지·지속 개선 요구사항을 정하는 표준이며, 서비스 수준 관리를 관계·합의 프로세스에 포함한다. [사실][^ref-708] 서비스 수준 협약(Service Level Agreement, SLA)은 그 합의를 문서로 정한 것이다.
- **산업데이터(Industrial Data)** — 산업 활동 과정에서 생성·활용되는 데이터를 가리키는 산업디지털전환촉진법의 용어다. [사실][^ref-637]
- **[적합성 시험(Conformance Test)](../../glossary/conformance-test.md)**, **[플릿 어댑터(Fleet Adapter)](../../glossary/fleet-adapter.md)**, **[플릿 제어 수준(Fleet Control Level)](../../glossary/fleet-control-level.md)** — 용어집 정의를 따른다. 이 영역에서의 쓰임은 6절에서 다룬다.
