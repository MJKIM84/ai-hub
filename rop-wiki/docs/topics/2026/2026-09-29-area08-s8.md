# 8. 채팅으로 맵 작성 — 대표 연구와 자료

## 1. 세 줄 요약

- Deguchi, Shibata, Taguchi, Language to Map(ICRA 2024) — 자연어 경로 지시문을 명시적 위상 지도로 바꾸며 암묵적 지도보다 정확도가 높았다. [사실][^ref-785] 언어만으로 위상 지도가 가능함을 보인 직접 근거다.
- 이 페이지는 [8. 채팅으로 맵 작성](../../categories/chat-based-configuration-and-operation/chat-map-authoring.md) 페이지의 "대표 연구와 자료" 절이 분량 기준을 넘어 옮겨 온 것이다. 원 페이지의 검증을 거친 내용이며 새 주장은 없다.

## 2. 배경

[8. 채팅으로 맵 작성](../../categories/chat-based-configuration-and-operation/chat-map-authoring.md) 페이지를 쓰는 과정에서 "대표 연구와 자료" 절의 분량이 세부영역 페이지 기준(4,000자)을 넘어, 내용을 줄이지 않고 이 주제 페이지로 분리했다.

## 3. 본문

- Deguchi, Shibata, Taguchi, Language to Map(ICRA 2024) — 자연어 경로 지시문을 명시적 위상 지도로 바꾸며 암묵적 지도보다 정확도가 높았다. [사실][^ref-785] 언어만으로 위상 지도가 가능함을 보인 직접 근거다.
- Rajendran Kathirvel 외, SENT-Map(ICRA 2025 워크숍) — 사람과 기반 모델이 함께 고치는 JSON 위상 지도. 대화와 화면 편집을 한 형식으로 잇는 참고. [사실][^ref-786]
- Walter 외, Learning Semantic Maps from Natural Language Descriptions(RSS 2013) — 언어와 센서를 결합한 의미 그래프 공동 추정. 언어가 지도 정확도를 올린 초기 근거. [사실][^ref-788]
- Leng 외, Tell2Design(ACL 2023) — 건축 설계용 언어 유도 평면도 생성 데이터셋. 공간·관계 제약이 난점임을 보임. [사실][^ref-787]
- Qin, Weber, Lu, HouseMind(CVPR 2026) — 건축 설계용. 방 단위 토큰으로 평면도 이해·생성·텍스트 편집을 한 모델에 통합. 우위 주장은 저자 보고값. [사실][^ref-813]
- Yang 외, Holodeck(CVPR 2024) — 건축·시뮬레이션 환경 생성용. 제약 생성 뒤 최적화 배치 구조. [사실][^ref-815]
- Rodionov 외, FloorplanQA(2025, v4 2026-05-25, ICML 2026) — 구조화 평면도 공간 추론 벤치마크. 물리 제약 미준수 약점 보고. [사실][^ref-812]
- Zhang 외, CAD 파일에서 실내 OSM 지도 생성(2025, v3 2026-03-31) — 연계 대상. 도면 해석 결과가 이 영역의 입력이 되는 경로. [사실][^ref-083]
- 김영재·김세윤·김홍준, 공공 맵 데이터 기반 전역 경로 계획용 지도 생성(대한공간정보학회지, 2022-06) — 국내 실외 위상 지도 구축 연구. [사실][^ref-811]
- 노주형 외, 탐사·엘리베이터 연계 완전 자율 다층 실내 지도 구축(로봇학회 논문지, 2026) — 연계 대상. 국내 다층 SLAM 지도화 연구. [사실][^ref-163]
