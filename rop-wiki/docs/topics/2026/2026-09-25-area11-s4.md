# 11. 분산 시스템·통신·컴퓨팅 구조 — 핵심 개념과 용어

## 3. 본문

2절의 질문을 다루려면 계산 계층, 분산 시스템의 이론적 한계, 통신 품질을 가리키는 용어를 먼저 맞춰야 한다. 아래 용어는 이 페이지 전체에서 같은 뜻으로 쓴다.

- **포그 컴퓨팅(Fog Computing)** — NIST SP 500-325(2018-03)는 포그 컴퓨팅을 클라우드와 말단 장치 사이에서 지연을 고려한 분산 애플리케이션을 지원하는 계층형 모델로 제시하고, 포그 노드가 논리적 위치와 통신 지연 비용을 알아 요청–응답 시간을 줄인다고 설명한다. [사실][^ref-303]
- **CAP 정리(CAP Theorem)** — Gilbert·Lynch(2002)는 비동기 네트워크 모델에서 분산 서비스가 일관성(Consistency)·가용성(Availability)·분할 내성(Partition tolerance)을 동시에 모두 만족할 수 없음을 증명해 Brewer의 추측을 정리로 만들었다. [사실][^ref-310]
- **서비스 품질(Quality of Service, QoS)** — ROS 2(Robot Operating System 2) QoS 설계 문서는 저가 로봇의 불안정한 무선망을 배경으로 이력·깊이·신뢰성(최선 노력/신뢰)·지속성 정책을 두고, 센서 데이터에는 완전성보다 적시성을 우선해 최선 노력 전송과 작은 큐를, 서비스·파라미터에는 신뢰 전송을 쓰는 프로파일을 제시한다. [사실][^ref-298]
- **베이스·호라이즌(Base / Horizon)** — [VDA 5050](../../glossary/vda-5050.md) 주문에서 관제가 이미 해제(release)해 로봇이 주행해도 되는 경로가 베이스, 계획만 되어 있고 아직 해제되지 않은 경로가 호라이즌이다(VDA 5050 3.0.0, main, 확인일 2026-09-25 기준). [사실][^ref-031]
- **세션 만료·메시지 만료·유언 메시지** — [MQTT](../../glossary/mqtt.md) 5.0 표준(2019-03)은 연결 종료 뒤 세션 상태(미확인 QoS 1 메시지·구독)를 보존하는 세션 만료 간격, 발행 메시지의 수명인 메시지 만료 간격, 연결이 끊긴 뒤 유언(will) 메시지 발행을 늦추는 유언 지연 간격, 여러 구독자에 메시지를 나누는 공유 구독을 둔다. [사실][^ref-306]
- **분산 발견(Distributed Discovery)** — ROS 2 설계 문서는 ROS 2가 DDS(Data Distribution Service)를 채택해 ROS 1의 중앙 마스터 없이 완전 분산 방식으로 참여자를 발견하게 했고, 이로써 마스터라는 단일 장애점을 없앴다고 설명한다. [사실][^ref-297]
