## 1. 세 줄 요약

- 여러 사업자를 한 현장에서 묶는 대표 접근은 판 번호 규칙으로 변경을 알리고, 적합성 시험으로 구현을 확인하고, 연동 수준을 나눠 통합하며, 서비스 수준과 감사 이력을 함께 기록하는 것이다. [의견]

## 3. 본문

여러 사업자를 한 현장에서 묶는 대표 접근은 판 번호 규칙으로 변경을 알리고, 적합성 시험으로 구현을 확인하고, 연동 수준을 나눠 통합하며, 서비스 수준과 감사 이력을 함께 기록하는 것이다. [의견]

### 판 번호와 변경 정책

VDA 5050 3.0.0 은 의미적 버전 관리를 따라 새 필수 필드 추가 같은 파괴적 변경은 주 버전, 선택 매개변수 추가 같은 기능 추가는 부 버전, 오타 수정은 수 버전으로 올리고, 메시지 헤더의 version 필드에 [Major].[Minor].[Patch] 형식의 프로토콜 판을 싣는다. [사실][^ref-031][^ref-051] 변경은 GitHub 이슈로 제안되고 월례 회의에서 논의되는 이슈에 진행 표시를, 수용된 변경에 반영 예정 판의 마일스톤을 붙여 관리하며, 3.0.1 은 오타·수정, 3.1.0 은 하위 호환 변경용이고 호환을 깨는 4.0.0 은 현재 계획되지 않았다(확인일 2026-09-25). [사실][^ref-634]

ROP 의 API 변경 정책은 상위 업무 시스템에 여는 API 에는 의미적 버전 관리와 폐기 예고·종료 시각 공지를 적용하고, 로봇 쪽에는 VDA 5050 헤더 version 처럼 로봇별 프로토콜 판을 기록해 판 차이를 관리하는 두 갈래로 설계할 수 있어 보인다. 물류 로봇 관제에 이 정책을 적용한 공개 사례는 확인하지 못했다. [추정][^ref-635][^ref-706][^ref-031][^ref-051]

### 적합성 시험과 인증

OPC Foundation 은 규격 적합성을 확인하는 적합성 시험 도구(CTT)를 제공하고, 제조사가 자체 인증하거나 재단이 인정한 독립 시험소의 인증을 받게 하며, 통과 제품에 인증 로고를 준다. [사실][^ref-705]

이번에 읽은 VDA 5050 3.0.0 명세와 저장소 README 에는 공식 적합성 시험·인증 절차가 정의되어 있지 않아 보이며, 확인한 VDA 5050 인증 근거는 제조사–관제 업체 간 인증 발표와 제3자 오픈소스 시험 도구뿐이다(부재 확정 아님). [추정][^ref-031][^ref-634][^ref-608][^ref-407][^ref-408] 예컨대 OTTO by Rockwell Automation 은 자사 AMR 이 Idealworks·NAiSE·SYNAOS 등 VDA 5050 관제 업체와 인증을 마쳤다고 발표했으나(2026-04), 인증의 시험 항목과 주체는 공개 자료로 확인되지 않았다. [추정] 벤더 주장[^ref-608]

### 연동 수준을 나눠 이종 관제를 통합

Open-RMF 는 플릿마다 [플릿 어댑터](../../glossary/fleet-adapter.md)가 제조사 고유 API 를 RMF 교통 일정·협상 인터페이스에 잇게 하고, 플릿 능력을 가정하지 않고 [플릿 제어 수준](../../glossary/fleet-control-level.md)을 전체 제어(Full Control)·신호등(Traffic Light)·읽기 전용(Read Only) 세 수준으로 나눠 제조사 관제를 통합한다. 인터페이스 없음(No Interface)은 RMF 와 호환되지 않는다. [사실][^ref-004]

### 서비스 수준·감사 이력·데이터 약정

이종 플릿 환경의 서비스 수준은 ROP 가 고객과 맺는 가용성·응답 목표가 제조사 관제·설비업체의 목표에 기대므로, 서비스 관리 표준의 서비스 수준 관리와 감사 추적 요구를 결합해 사업자별 목표와 장애 귀책을 기록으로 확인하는 구조가 필요해 보인다. [추정][^ref-708][^ref-707]

로봇 상태·운행 기록처럼 제조사 로봇, ROP, 현장 운영사가 함께 만드는 데이터는 국내법상 공동 생성 데이터로 볼 여지가 있어, 약정이 없으면 각 사업자가 사용·수익 권리를 가지므로 연동 계약에서 데이터 범위·이용 목적·제3자 제공을 따로 정해야 할 것으로 보인다. 법률 해석과 국내 계약 사례는 확인하지 못했다. [추정][^ref-637][^ref-636]
