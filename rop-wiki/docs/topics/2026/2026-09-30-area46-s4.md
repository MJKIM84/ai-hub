# 46. 예측·학습 기반 최적화 — 핵심 개념과 용어

## 3. 본문

아래는 이 페이지에서 쓰는 주요 용어다.

- **결정 중심 학습(Decision-Focused Learning)** — 예측 모델을 예측 오차가 아니라 그 예측으로 푼 최적화 문제의 결정 손실이 작아지도록 학습하는 방법이다. 대표 방법인 Smart "Predict, then Optimize"(SPO)는 결정 손실(SPO 손실)과 그 볼록 대리 손실(SPO+)로 최적화 문제의 목적·제약을 학습에 반영한다. [사실][^ref-1061]
- **모방 학습(Imitation Learning)** — 전문가(예: 탐색 기반 계획기)가 만든 해를 정답으로 삼아 같은 결정을 흉내 내는 정책을 학습하는 방법이다. 경로 찾기에서는 전문가 해의 대규모 데이터셋을 트랜스포머로 모방학습한 연구가 있다. [사실][^ref-1055][^ref-199]
- **안내 그래프(Guidance Graph)** — [지속형 다중 에이전트 경로 찾기](../../glossary/lifelong-mapf.md)(Lifelong Multi-Agent Path Finding, Lifelong MAPF) 알고리즘이 따르는 격자 간선 가중치다. 배치 전에 오프라인으로 최적화하거나 가중치를 생성하는 모델을 학습해 교통 흐름을 유도한다. [사실][^ref-1064]
- **예지(Prognostics)와 예지 정비(Predictive Maintenance)** — ISO 13381-1은 기계 상태 감시·진단에서 예지의 일반 지침을 정한 표준이다. [사실][^ref-1060] 예지 정비는 상태 신호로 고장을 미리 예측해 정비 시점과 조치를 정하는 방식이며, 청소 로봇의 진동 분류 결과를 지도에 겹친 예지 정비 지도가 그 예다. [사실][^ref-1057] 관련 용어: [상태 기반 정비](../../glossary/condition-based-maintenance.md).
- **분포 이동(Distribution Shift)** — 운영 중 들어오는 요청의 양상이 학습·예측 때와 달라지는 상황이다. 병원 배정 연구는 최근 예측 오차에 따라 예측 요청의 가중치를 다시 매겨 이에 대응했다. [사실][^ref-1062]
- **[충전 상태](../../glossary/state-of-charge.md)(State of Charge, SoC)** — 배터리 소모 예측 모형의 입력 항목으로 쓰였다. [사실][^ref-1058]
- **[다중 로봇 작업 배정](../../glossary/mrta.md)(Multi-Robot Task Allocation, MRTA)** — 학습 기반 배정은 이 문제를 강화학습 정책으로 푼다. [사실][^ref-623]
