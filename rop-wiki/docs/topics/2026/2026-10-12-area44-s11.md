## 3. 본문

(상태: 열림 · 제기 2026-09-30 · 실행 2026-09-30-07) 로봇 기반 모델(VLA)을 탑재해 명시적 스킬 목록 없이 학습된 범용 기능을 가진 로봇의 능력을 플랫폼의 능력 모델에 어떻게 등록·기술하고 검증할 것인가?


### 2026-10-12 갱신: 부분 근거와 새 질문

이 절의 2026-09-30 본문은 [44. 로봇 기반 모델·언어 모델 계획 — 열린 질문 (2026-09-30)](2026-09-30-area44-s11.md)에 있다.

아래 기존 질문에는 부분 근거만 더했으며, 모두 열림 상태를 유지한다.

- **oq-216** (상태: 열림) 부분 근거: 배포물마다 입출력이 다르다. OpenVLA는 정규화된 7자유도 엔드이펙터 변위를 내고 로봇·데이터셋별 역정규화가 필요하며, openpi 원격 추론은 행동 청크를 돌려주고 남은 행동을 개방 루프로 실행하도록 안내한다(7절). [사실][^ref-1534][^ref-1535] π0.7 보고서는 프롬프트로 관절·엔드이펙터 제어 모드를 고른다고 설명한다(8절). [추정] 벤더 주장[^ref-1538] 공통 능력 등록 표준과 적합성 시험은 확인하지 못했다.
- **oq-217** (상태: 열림) 부분 근거: 확인한 공개 평가는 SMART-LLM(AI2-THOR 지시 36개, 로봇 1~4대), IMR-Bench(장면 23개·제조 작업 50개, 장면당 로봇 1~7대), S-ATLAS(AI2-THOR 검증 시나리오 110개, 로봇 1·3·10·15대)이고, 실물 시험으로는 IMR-LLM의 로봇 팔 3대 단일 장면을 확인했다(5절·6절). [사실][^ref-090][^ref-170][^ref-1532] VLA 쪽에는 입력 교란 견고성 벤치마크 LIBERO-Plus가 있다(8절). [사실][^ref-1539] 설비·안전·시간창을 함께 다루는 공통 기준은 확인하지 못했다.
- **oq-218** (상태: 열림) 관련 근거: 산업부 M.AX 휴머노이드 AI 파운데이션 모델 과제 보도자료(2025-11-24)에도 실측 결과는 없다(5절). [사실][^ref-1546]
- **oq-219** (상태: 열림) 부분 근거: 10개월은 BMW 보도자료 본문, 11개월은 Figure AI 최고경영자 인용문에 있고, Figure AI 발표는 6·10·11개월의 다른 기간 축을 적는다. 기점·종점이 없어 충돌은 해소되지 않았다(5절). [추정] 벤더 주장[^ref-1051][^ref-1544]
- **oq-104** 관련 근거: π0.7 보고서의 240 ms(50 Hz 기준)는 학습 중 모사한 지연이며 측정된 추론 지연이 아니다(8절). [추정] 벤더 주장[^ref-1538]
- **oq-141**([13. 대화형 기능의 신뢰·기반](../../categories/chat-based-configuration-and-operation/conversational-trust-and-foundations.md) 쪽 승인 관문 위치 질문) 관련 근거: MoveIt Pro MCP 서버는 확인 프롬프트를 두지 않고 도구 승인을 MCP 클라이언트 설정에 맡긴다(9절). 이 페이지에서 상태를 바꾸지 않는다. [추정] 벤더 주장[^ref-1543]

이번에 새로 올린 질문(전체 목록은 [열린 질문](../../open-questions.md)):

- (상태: 열림 · 제기 2026-10-12 · 실행 2026-10-12-05) 언어 모델 다중 로봇 계획의 검증이 기대는 가정(사람이 준 도메인 판, i.i.d. 시나리오, 무오류 스킬 실행)을 런타임에서 누가 감시하고, 가정이 깨졌을 때 어떤 계획을 중단·재검증할 것인가?

- (상태: 열림 · 제기 2026-10-12 · 실행 2026-10-12-05) 출처 충돌: OpenVLA 공개 가중치의 사용 조건은 저장소 README(Llama 2 파생이라 Llama Community License 가 적용될 수 있음)와 Hugging Face 모델 카드(모든 체크포인트 MIT) 가운데 어느 쪽인가?
