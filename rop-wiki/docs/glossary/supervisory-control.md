# 감독 제어 (Supervisory Control)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 감독 제어 | Supervisory Control | 없음 |

## 한 줄 정의

사람이 개별 동작을 조작하지 않고 시스템이 제안한 계획을 검토·승인하거나 필요할 때만 개입하는 방식으로 여러 로봇의 실행을 감독하는 제어 형태다. [추정][^ref-165][^ref-849]

## 설명

Li 외(2025)의 다중 로봇 언어 모델 서베이는 실행 전 사람 승인(Hunt 외), 로봇의 도움 요청(VADER), 사람 검증(HMCF)을 사람 개입의 예로 들면서, 사람이 반응적 역할에 머물고 로봇 수가 늘 때 운영자 인지 부담이 정량화되지 않았다고 지적했다.
