# 사용자 정의 속성 세트 (User-defined Property Set)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 사용자 정의 속성 세트 | User-defined Property Set | 없음 |

## 한 줄 정의

IFC 명세에 선언되지 않은 프로젝트·조직 고유의 속성 묶음으로, 명세 정의 세트에만 쓰는 'Pset_' 접두어 없이 이름을 짓고 개별 객체에는 IfcRelDefinesByProperties 로, 유형 객체에는 직접 연결로 붙인다. [추정][^ref-1357][^ref-1364]

## 설명

아직 작성되지 않음
