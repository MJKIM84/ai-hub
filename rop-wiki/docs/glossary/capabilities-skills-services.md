# 능력·스킬·서비스 모델 (Capabilities, Skills and Services (CSS) Model)

## 한 줄 정의

Plattform Industrie 4.0 작업반이 제안한 정보 모델로, 구현과 무관한 기능 명세(능력)와 그 실행 가능한 구현(스킬), 제공 형태(서비스)를 구분한다. 이 위키의 온톨로지 초안에서는 CSS의 능력(capability)을 기능(Capability)으로 부른다. [추정][^ref-035][^ref-036]
