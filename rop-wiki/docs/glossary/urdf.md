# 통합 로봇 기술 형식 (Unified Robot Description Format (URDF))

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|

## 한 줄 정의

로봇의 링크와 관절로 구조·운동학·물리 속성을 기술하는 ROS 계열의 XML 형식으로, 식별자 자체에는 의미가 없어 온톨로지로 옮기려면 해석이 필요하다. [추정][^ref-239]

## 설명

URDF 공식 문서는 이번 실행에서 열지 못했고, 정의는 URDF 온톨로지 채우기 연구의 초록에 기댄다.
