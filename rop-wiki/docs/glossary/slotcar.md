# 슬롯카 모델 (Slotcar (Open-RMF simulated robot plugin))

## 용어

## 한 줄 정의

Open-RMF 시뮬레이션에서 플릿 어댑터의 경로·모드 요청을 받아 경유점 사이를 레일식 직선으로 움직이고 장애물이 있으면 멈추는 단순화 로봇 모델로, 로봇마다 주행 스택을 돌리지 않고 플릿 조율·설비 상호작용을 시험하게 한다. [추정][^ref-406]
