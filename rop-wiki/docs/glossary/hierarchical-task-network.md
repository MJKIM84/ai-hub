# 계층적 작업 네트워크 (Hierarchical Task Network (HTN))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 계층적 작업 네트워크 | Hierarchical Task Network (HTN) | HTN — Hierarchical Task Network |

## 한 줄 정의

복합 작업을 미리 정한 분해 방법으로 하위 작업 네트워크로 나누어 결국 실행 가능한 기본 동작의 순서에 이르게 하는 자동 계획 방식이다. [추정][^ref-501]

## 설명

HDDL 은 이 방식의 계획 문제를 기술하는 공통 언어로, 작업을 하위 작업·동작의 부분 또는 전체 순서 네트워크로 분해하는 방법을 기술한다.
