# 역할 기반 접근 통제 (Role-Based Access Control (RBAC))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 역할 기반 접근 통제 | Role-Based Access Control (RBAC) | RBAC — Role-Based Access Control |

## 한 줄 정의

사용자에게 역할을 주고 역할에 동작 권한을 묶어, 사용자가 가진 역할에 따라 어떤 자원에 어떤 동작을 할 수 있는지 정하는 접근 통제 방식이다. [추정][^ref-762]

## 설명

Open-RMF 웹 API 서버는 역할·동작·인가 그룹의 조합으로 사용자의 작업 제출 등 동작 권한을 정한다.
