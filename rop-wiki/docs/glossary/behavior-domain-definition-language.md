# 행동 영역 정의 언어 (Behavior Domain Definition Language (BDDL))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 행동 영역 정의 언어 | Behavior Domain Definition Language (BDDL) | BDDL — Behavior Domain Definition Language |

## 한 줄 정의

BEHAVIOR 벤치마크가 일상 가정 활동을 형식 명세하는 데 쓰는 도메인 특화 언어다. [추정][^ref-971]

## 설명

BEHAVIOR-1K 는 설문으로 고른 일상 가정 활동 1,000개를 BDDL 로 명세하고 OmniGibson 시뮬레이터에 구현했다.
