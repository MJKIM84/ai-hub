# LLM 에이전트 (LLM Agent)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| LLM 에이전트 | LLM Agent | 없음 |

## 한 줄 정의

대규모 언어 모델이 사람이 정해 준 도구·함수(로봇 API, 조회 기능 등)를 골라 호출하며 여러 단계로 작업을 수행하도록 구성한 소프트웨어이다. [추정][^ref-171][^ref-172][^ref-175]

## 설명

ROSA는 개발자가 도구 함수 목록을 넘겨 에이전트가 쓸 수 있는 행동을 정하고, RAI는 ROS 2용 에이전트 프레임워크로 공개되어 있다.
