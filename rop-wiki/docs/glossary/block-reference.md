# 블록 참조 (Block Reference (INSERT))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 블록 참조 | Block Reference (INSERT) | INSERT — Block Reference |

## 한 줄 정의

CAD 도면에서 여러 번 재사용하는 엔터티 묶음(블록)을 위치·회전·축척을 주어 한 번 배치한 것으로, 태그가 붙은 속성 텍스트(ATTRIB)를 달아 메타데이터를 실을 수 있다. [추정][^ref-424][^ref-434]

## 설명

ezdxf 문서 기준 설명이다. 도면 인식 연구(ArchCAD-400K)는 CAD 도면의 레이어·블록 계층을 자동 라벨링에 이용한다.
