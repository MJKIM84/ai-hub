# 공공 영역 이동로봇 (Public-area Mobile Robot (PMR))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 공공 영역 이동로봇 | Public-area Mobile Robot (PMR) | PMR — Public-area Mobile Robot |

## 한 줄 정의

보도·연석 같은 공공 공간에서 보호받지 않는 보행자 곁을 다니며 배송·점검·감시 등을 하는 로봇으로, ISO/TC 204 의 ISO 4448 시리즈가 쓰는 용어다. [추정][^ref-989][^ref-994]
