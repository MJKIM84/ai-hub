# 엄격 스키마 (Strict Schema (deprecated elements removed))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 엄격 스키마 | Strict Schema (deprecated elements removed) | deprecated elements removed — Strict Schema |

## 한 줄 정의

형식의 판에서 폐기 예정 요소를 뺀 검증용 스키마로, 기존 시나리오 파일을 이 스키마로 검사해 다음 판에서 사라질 요소를 찾아 바꾸게 한다(ASAM OpenSCENARIO XML). [추정][^ref-1303]
