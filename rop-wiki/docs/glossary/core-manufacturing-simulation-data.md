# 핵심 제조 시뮬레이션 데이터 (Core Manufacturing Simulation Data (CMSD))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 핵심 제조 시뮬레이션 데이터 | Core Manufacturing Simulation Data (CMSD) | CMSD — Core Manufacturing Simulation Data |

## 한 줄 정의

제조 분야 시뮬레이션과 정보 시스템 사이 데이터 교환을 위한 SISO 표준 중립 정보 모델이다. [추정][^ref-631]

## 설명

레이아웃·자원·주문·재고·일정·달력·분포 같은 엔터티를 두며 UML 판(SISO-STD-008-2010)과 XML 판(SISO-STD-008-01-2012)으로 발행되었다. 대상은 제조이며 물류 적용은 확인되지 않았다.
