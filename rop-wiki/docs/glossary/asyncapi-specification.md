# AsyncAPI 명세 (AsyncAPI Specification)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| AsyncAPI 명세 | AsyncAPI Specification | 없음 |

## 한 줄 정의

MQTT·AMQP·WebSocket·Kafka 같은 메시지 기반 API 의 채널·동작·메시지·브로커를 기계가독 형식으로 기술하는 프로토콜 중립 명세다. [추정][^ref-1024]

## 설명

3.1.0 은 채널·동작(send/receive)·메시지·서버·프로토콜별 바인딩을 핵심 객체로 두며 Apache 2.0 라이선스로 공개된다.
