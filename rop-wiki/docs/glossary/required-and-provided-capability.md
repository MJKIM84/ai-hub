# 요구 능력·제공 능력 (Required Capability / Provided (Offered) Capability)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 요구 능력·제공 능력 | Required Capability / Provided (Offered) Capability | 없음 |

## 한 줄 정의

공정·작업 쪽이 필요로 하는 능력과 자원 쪽이 내놓는 능력을 구분한 표현으로, 둘을 비교해 작업을 맡을 자원을 정한다. 이 위키의 온톨로지 초안에서는 capability 를 기능으로 부르므로 요구·제공 한정자에 해당한다. [추정][^ref-229][^ref-327]

## 설명

IDTA 02020 능력 기술 1.0 README 는 요구 능력과 제공 능력의 비교가 생산 계획·오케스트레이션을 돕는다고 설명한다. 능력 온톨로지 초안 v0.3 은 기능에 한정자(요구 / 제공) 속성을 두었다.
