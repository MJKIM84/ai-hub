# MQTT 유언 메시지 (MQTT Last Will (Will Message))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| MQTT 유언 메시지 | MQTT Last Will (Will Message) | Will Message — MQTT Last Will |

## 한 줄 정의

MQTT 클라이언트가 접속할 때 브로커에 맡겨 두고, 연결이 예기치 않게 끊기면 브로커가 대신 발행하는 메시지다. VDA 5050 은 이를 써서 로봇의 연결 끊김(CONNECTION_BROKEN)을 알린다. [추정][^ref-031]
