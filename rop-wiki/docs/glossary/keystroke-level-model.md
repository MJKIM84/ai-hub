# 키 입력 수준 모델 (Keystroke-Level Model (KLM))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 키 입력 수준 모델 | Keystroke-Level Model (KLM) | KLM — Keystroke-Level Model |

## 한 줄 정의

숙련 사용자가 오류 없이 과제를 수행하는 시간을 키 입력·포인팅·정신적 준비 같은 연산자 시간의 합으로 예측하는 GOMS 계열 모델이다. [추정][^ref-802]

## 설명

숙련·무오류 가정이므로 판단·확인 시간과 오류 수정 시간은 담지 않는다. 건축 도면 자동 인식 트랙에서는 현장 실측이 어려울 때의 보조 추정 방법으로만 거론된다(추정).
