# 모바일 매니퓰레이터 (Mobile Manipulator)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 모바일 매니퓰레이터 | Mobile Manipulator | 없음 |

## 한 줄 정의

AMR·AGV 같은 이동 플랫폼에 로봇팔을 결합해 이동과 집기·놓기 작업을 함께 수행하는 로봇이다. [추정][^ref-210]

## 설명

ANSI/A3 R15.08-2-2023 은 매니퓰레이터를 단 이동로봇을 산업용 이동로봇(IMR) 유형 C 로 다룬다.
