# 소프트웨어 명판 (Software Nameplate (IDTA 02007))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 소프트웨어 명판 | Software Nameplate (IDTA 02007) | IDTA 02007 — Software Nameplate |

## 한 줄 정의

자산관리셸에서 소프트웨어 제품과 설치 인스턴스의 식별·버전·설치 정보를 통일된 형태로 기술하는 서브모델이다. [추정][^ref-550]

## 설명

업데이트·패치 관리·라이선스 관리·감사를 목적으로 하며 버전(주·부·개정·빌드), 배포일·빌드일·설치일, 설치 경로·체크섬 같은 속성을 둔다.
