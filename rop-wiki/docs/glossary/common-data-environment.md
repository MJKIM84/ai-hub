# 공통 데이터 환경 (Common Data Environment (CDE))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 공통 데이터 환경 | Common Data Environment (CDE) | CDE — Common Data Environment |

## 한 줄 정의

ISO 19650 정보 관리에서 도면·모델 같은 정보 컨테이너를 상태·개정 메타데이터와 함께 관리하는 환경(영국 국가 부속서 기반 지침 기준). [추정][^ref-689]

## 설명

영국 BIM Framework 지침 Part C(2020-09)는 정보 컨테이너 메타데이터에 상태·개정 코드를 둔다. 상태 목록(작업 중·공유·발행·보관)은 업체 블로그 요약 기준이며 ISO 19650 발행 기관 자료는 열람하지 못했다. 로봇 지도 관리에서는 도면 개정을 식별하는 근거 후보가 된다.
