# GLN 확장 성분 (GLN Extension Component)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| GLN 확장 성분 | GLN Extension Component | 없음 |

## 한 줄 정의

물리적 위치를 가리키는 GS1 위치 코드(GLN)에 덧붙여 그 시설 안의 구역·선반 같은 하위 위치를 식별하는 GS1 의 코드 성분이다. [추정][^ref-1397]

## 설명

물리적 위치를 식별하는 GLN 과 함께만 쓴다(원문 미열람, 검색 결과 요약 기준).
