# IT/OT 융합 (IT/OT Convergence)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| IT/OT 융합 | IT/OT Convergence | 없음 |

## 한 줄 정의

정보기술의 데이터 처리와 운영기술의 물리 제어를 실시간 데이터 교환으로 잇는 흐름이다. [추정][^ref-902]

## 설명

IFR 은 2026년 동향에서 IT/OT 융합을 로봇의 범용성을 넓히는 항목으로 들었다(출처 ref-902). 로봇 관제·오케스트레이션이 업무 시스템과 설비 사이에 놓이는 배경이 된다.
