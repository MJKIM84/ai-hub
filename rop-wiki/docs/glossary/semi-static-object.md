# 반정적 객체 (Semi-static Object)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 반정적 객체 | Semi-static Object | 없음 |

## 한 줄 정의

팔레트·랙·가구처럼 로봇이 관측하는 동안은 움직이지 않지만 시간이 지나면 위치가 바뀌거나 나타나고 사라져 정적 지도를 낡게 만드는 물체다. [추정][^ref-654][^ref-653]

## 설명

물류 시설에서는 팔레트 임시 적치가 대표 예이며, 반정적 객체의 변화를 추적·갱신하는 SLAM·지도 갱신 연구는 로봇 쪽 연계 대상이다.
