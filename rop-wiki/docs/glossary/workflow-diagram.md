# 워크플로 다이어그램 (Workflow Diagram (Open-RMF 상호운용 관심 그룹 제안))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 워크플로 다이어그램 | Workflow Diagram (Open-RMF 상호운용 관심 그룹 제안) | 없음 |

## 한 줄 정의

Open-RMF 진영이 제안한, 그래픽 다이어그램으로 나타낼 수 있는 워크플로를 사람이 읽을 수 있는 JSON 스키마로 정의한 형식으로, 행동 트리로 표현하기 어려운 분기·동기화·순환을 담고 실행 전에 빌드 오류를 검사한다. crossflow 와의 관계는 미확인이다. [추정][^ref-1349][^ref-1350]

## 설명

근거는 Open Robotics Discourse 포럼의 Open-RMF 상호운용 관심 그룹 공지(2024-07-25, 2025-05-31)이며 JSON 스키마 원문은 열람하지 못했다.
