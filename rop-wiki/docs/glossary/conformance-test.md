# 적합성 시험 (Conformance Test)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 적합성 시험 | Conformance Test | 없음 |

## 한 줄 정의

구현이 표준·명세가 정한 메시지 형식과 동작 규칙을 지키는지 정해진 시나리오로 확인하는 시험이다. [추정][^ref-407]

## 설명

VDA 5050 3.0.0 에 대해서는 제3자 오픈소스 시뮬레이터(vda5050-sim)가 적합성 시험 묶음을 둔다고 README 에 적고 있으나, VDA·VDMA 공식 적합성 시험은 아니다.
