# ECLASS (ECLASS)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| ECLASS | ECLASS | 없음 |

## 한 줄 정의

ECLASS e.V. 가 관리하는 제품·서비스 분류·속성 사전 표준으로, 4단계 계층의 8자리 코드와 IRDI 로 분류 클래스와 속성을 식별한다. [추정][^ref-184][^ref-392]

## 설명

각 분류 클래스는 고유 식별자(IRDI)·우선 명칭·코드를 가지며, IRDI 의 코드 공간 01 은 분류 클래스를 뜻한다.
