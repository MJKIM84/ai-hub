# 사용 정보 (Information for Use (Instructions for Use))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 사용 정보 | Information for Use (Instructions for Use) | Instructions for Use — Information for Use |

## 한 줄 정의

제조사가 제품 사용자에게 제공하는 설명 정보로, IEC/IEEE 82079-1:2019 가 모든 종류 제품의 사용 정보 작성 원칙과 요구사항을 정한다. [추정][^ref-510][^ref-509]

## 설명

IEC/IEEE 82079-1:2019 는 2012 초판을 대체하며 정보 품질·정보 관리 과정과 사용 정보의 실증적 평가 방법을 규범 부분에 둔다(원문 미열람). 기계 설명서의 안전 관련 부분은 ISO 20607:2019 가 따로 정한다. 로봇 매뉴얼은 능력 온톨로지의 근거 문서가 된다.
