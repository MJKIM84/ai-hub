# 상태 기반 정비 (Condition-Based Maintenance (CBM))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 상태 기반 정비 | Condition-Based Maintenance (CBM) | CBM — Condition-Based Maintenance |

## 한 줄 정의

정해진 주기 대신 상태 감시로 확인한 설비 상태에 따라 정비 여부와 시점을 정하는 정비 방식이다. [추정][^ref-553][^ref-551]

## 설명

산업용 로봇 분야에서는 고장 모드 분석, 데이터 수집·센서, 모델 기반·데이터 기반 상태 감시·고장 진단 기법이 상태 기반 정비 구현 관점에서 정리돼 있다.
