# 작업장 스케줄링 문제 (Job Shop Scheduling Problem (JSSP))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 작업장 스케줄링 문제 | Job Shop Scheduling Problem (JSSP) | JSSP — Job Shop Scheduling Problem |

## 한 줄 정의

여러 작업이 정해진 순서로 여러 기계를 거칠 때 기계별 작업 순서를 정해 전체 완료 시간 같은 목표를 최소화하는 대표적 조합 최적화 스케줄링 문제이다. [추정][^ref-595]

## 설명

LLM 이 스케줄을 직접 만드는 연구(Starjob 등)의 평가 대상으로 쓰인다.
