# 대조적 설명 (Contrastive Explanation)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 대조적 설명 | Contrastive Explanation | 없음 |

## 한 줄 정의

시스템이 왜 다른 선택(예: 다른 로봇·다른 일정)이 아니라 이 선택을 했는지를 대안과 비교해 설명하는 방식으로, 사용자가 명세 오류를 찾는 데 쓰인다. [추정][^ref-662]

## 설명

다중 로봇 시스템에서는 작업 배정·스케줄링·경로 계획 정보를 골라 써서 해를 대조적으로 설명하는 방법(CE-MRS)이 연구되었다. 저자 보고 사용자 연구의 조건은 수색·구조 영역이다.
