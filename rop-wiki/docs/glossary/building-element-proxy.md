# 건물 요소 프록시 (Building Element Proxy (IfcBuildingElementProxy))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 건물 요소 프록시 | Building Element Proxy (IfcBuildingElementProxy) | IfcBuildingElementProxy — Building Element Proxy |

## 한 줄 정의

IFC 4.3 개발 브랜치 기준으로, 명세가 아직 정의하지 않았거나 응용이 의미 정의에 대응시킬 수 없는 건축 요소를 교환하는 IFC 엔터티이며, PredefinedType 을 USERDEFINED 로 두면 ObjectType 으로 유형 이름을 적어야 하고 IFC4.3.0.0 부터는 공간 자리표시·예비 공간 용도로 쓰지 않는다(그 용도는 IfcVirtualElement). [추정][^ref-1356]
