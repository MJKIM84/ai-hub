# 출처 근거 연결 (Source Grounding)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 출처 근거 연결 | Source Grounding | 없음 |

## 한 줄 정의

언어 모델이 문서에서 추출한 항목마다 원문 속 정확한 위치를 함께 기록해 사람이 원문과 대조해 확인할 수 있게 하는 방식이다. [추정][^ref-1074]

## 설명

오픈소스 LangExtract 는 추출 항목마다 원문 위치를 연결하고 원문 맥락에 강조해 보여 주는 HTML 검토 화면을 만든다.
