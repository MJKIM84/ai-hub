# 구조화 출력 (Structured Output)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 구조화 출력 | Structured Output | 없음 |

## 한 줄 정의

LLM 의 응답을 JSON 스키마 같은 정해진 형식의 필드와 값으로 내도록 제약하는 방식이다. [추정][^ref-362]

## 설명

OpenAI는 구조화 출력 기능이 모델 출력을 개발자가 준 JSON 스키마에 맞추도록 보장해 필수 키 누락을 막는다고 설명한다(2024-08 발표, 벤더 주장).
