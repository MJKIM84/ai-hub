# 그래프 편집 거리 (Graph Edit Distance (GED))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 그래프 편집 거리 | Graph Edit Distance (GED) | GED — Graph Edit Distance |

## 한 줄 정의

한 그래프를 다른 그래프로 바꾸는 노드·엣지 추가·삭제·치환의 최소 비용으로, 평면도 방 연결 그래프의 구조 차이를 재는 데 쓴다. [추정][^ref-720]

## 설명

SSIG 는 평면도 구조 유사도를 IoU 와 방 연결 그래프의 GED 가중합으로 정의한다.
