# 계층 도메인 정의 언어 (Hierarchical Domain Definition Language (HDDL))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 계층 도메인 정의 언어 | Hierarchical Domain Definition Language (HDDL) | HDDL — Hierarchical Domain Definition Language |

## 한 줄 정의

PDDL 을 확장해 작업·분해 방법과 하위 작업의 부분 또는 전체 순서를 기술하는 계층적 작업 네트워크 계획 문제의 공통 기술 언어이다. [추정][^ref-501]

## 설명

Höller 외가 제안했고(arXiv 2019-11, AAAI 2020 게재) 2020년 국제 계획 경진대회 첫 계층 계획 부문의 공통 언어로 만들어졌다.
