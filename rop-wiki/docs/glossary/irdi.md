# 국제 등록 데이터 식별자 (International Registration Data Identifier (IRDI))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 국제 등록 데이터 식별자 | International Registration Data Identifier (IRDI) | IRDI — International Registration Data Identifier |

## 한 줄 정의

ECLASS·IEC CDD 같은 데이터 사전이 속성·분류 클래스를 기관 식별자와 코드 공간·항목 코드·버전으로 고유하게 가리키는 식별자 형식이다(예: 최대 적재 질량 속성의 ECLASS IRDI 0173-1#02-ABJ258#001). [추정][^ref-392][^ref-245]

## 설명

ECLASS IRDI 에서 코드 공간 01 은 분류 클래스, 02 는 속성을 뜻한다(원문 미열람). IDTA 02047 무인운반차 기술 데이터 템플릿은 최대 적재 질량 같은 속성의 의미 식별자로 ECLASS IRDI 를 쓴다. 관련 용어: [의미 식별자](semantic-id.md).
