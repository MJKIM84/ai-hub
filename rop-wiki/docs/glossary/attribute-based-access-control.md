# 속성 기반 접근 통제 (Attribute-Based Access Control (ABAC))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 속성 기반 접근 통제 | Attribute-Based Access Control (ABAC) | ABAC — Attribute-Based Access Control |

## 한 줄 정의

주체·객체·요청 동작의 속성과 시간·위치 같은 환경 조건을 정책에 대조해 허용 여부를 정하는 접근 통제 방식이다. [추정][^ref-768]

## 설명

NIST SP 800-162(2014-01 판)가 정의한다. 채팅 지시의 명령 권한에서 교대조·시간대 같은 환경 조건을 대조하는 근거로 쓰인다.
