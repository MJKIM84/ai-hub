# 설명 가능한 다중 에이전트 경로 찾기 (Explainable Multi-Agent Path Finding (Explainable MAPF))

## 용어

## 한 줄 정의

여러 에이전트의 충돌 없는 경로를 찾으면서, 궤적이 서로 겹치지 않는 시간 구간 이미지 몇 장만으로 사람이 계획의 안전을 눈으로 확인할 수 있게 하는 경로 계획 문제다. [추정][^ref-1098]

## 설명

설명 개념은 선행 연구가 제안했고, Kottinger 외(ICAPS 2022)는 충돌 기반 탐색에 설명 가능성 제약을 더한 XG-CBS를 제안했다.
