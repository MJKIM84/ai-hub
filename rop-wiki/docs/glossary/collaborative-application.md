# 협동 적용 (Collaborative Application)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 협동 적용 | Collaborative Application | 없음 |

## 한 줄 정의

ISO 10218:2025 에서 로봇 자체가 아니라 사람과 로봇이 함께 일하도록 설계된 적용 방식을 기준으로 안전을 판단하기 위해 '협동로봇' 대신 쓰는 용어이다. [추정][^ref-471]

## 설명

A3 해설 기준이며 ISO 원문은 미열람이다.
