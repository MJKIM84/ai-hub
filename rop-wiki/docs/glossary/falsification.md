# 반증 기반 시험 (Falsification)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 반증 기반 시험 | Falsification | 없음 |

## 한 줄 정의

시나리오 공간을 탐색해 시스템이 명세(예: 시간 논리 요구)를 어기는 반례 시나리오를 찾아내는 시뮬레이션 기반 검증 방법이다. [추정][^ref-1086]

## 설명

확률적 시나리오 언어 Scenic 3.0 은 3차원 기하·가시성 판정·LTL 시간 요구를 더해 반증 기반 시험에 쓸 수 있게 했다.
