# 문서 레이아웃 분석 (Document Layout Analysis)

## 한 줄 정의

문서 페이지 이미지나 PDF 에서 본문·제목·표·그림·수식 같은 영역을 찾아 종류를 구분하고 읽는 순서를 정하는 문서 이해의 첫 단계다. [추정][^ref-1068][^ref-1067]

## 설명

Docling 은 DocLayNet 기반 모델로 레이아웃을 분석하고, OmniDocBench 는 19개 레이아웃 범주로 파싱 결과를 평가한다.
