# 완전 정보의 기대 가치 (Expected Value of Perfect Information (EVPI))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 완전 정보의 기대 가치 | Expected Value of Perfect Information (EVPI) | EVPI — Expected Value of Perfect Information |

## 한 줄 정의

불확실한 값을 정확히 알게 될 때 기대되는 결정 결과의 개선량으로, 되물을 질문을 고를 때 질문 비용과 비교하는 기준으로 쓰인다. [추정][^ref-664]

## 설명

SAGE-Agent 는 질문마다 EVPI 와 질문 비용을 따져 되물을 질문을 고른다고 보고했다(저자 보고, 원문 미열람, 도구 호출 조건).
