# 명시적 확인·암시적 확인 (Explicit / Implicit Confirmation)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 명시적 확인·암시적 확인 | Explicit / Implicit Confirmation | 없음 |

## 한 줄 정의

대화 시스템이 이해한 내용을 사용자에게 직접 물어 승인받는 방식(명시적)과, 다음 응답 속에 이해한 내용을 되풀이해 보여 주고 사용자가 고치지 않으면 진행하는 방식(암시적)이다. [추정][^ref-717]

## 설명

음성 대화 시스템 연구(Sagawa 외, INTERSPEECH 2004)는 명시적·최종·암시적 확인을 비교했으며, 비교 결과의 우열은 이 위키에서 확인하지 못했다.
