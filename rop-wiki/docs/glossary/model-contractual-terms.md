# 모델 계약 조항 (Model Contractual Terms (MCTs))

|---|---|---|

## 한 줄 정의

EU 집행위원회가 데이터법 이행을 위해 데이터 보유자·사용자·데이터 수령자 사이의 데이터 접근·이용 계약에 쓰도록 권고하는 구속력 없는 표준 계약 문안이다. [추정][^ref-1192]
