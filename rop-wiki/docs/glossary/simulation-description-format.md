# 시뮬레이션 기술 형식 (Simulation Description Format (SDFormat))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 시뮬레이션 기술 형식 | Simulation Description Format (SDFormat) | SDFormat — Simulation Description Format |

## 한 줄 정의

Gazebo 에서 시작해 Open Source Robotics Foundation 이 관리하는, 로봇과 환경·물리 설정을 시뮬레이터·시각화·제어용으로 기술하는 XML 형식이다. [추정][^ref-1092]

## 설명

로봇의 기구학·동역학·센서와 조명·지형·OpenStreetMap 도로·3D 모델 같은 환경을 기술하며 Apache 2.0 으로 공개된다.
