# 웹훅 (Webhook)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 웹훅 | Webhook | 없음 |

## 한 줄 정의

어떤 사건이 일어났을 때 서비스가 미리 등록된 외부 URL 로 HTTP 요청을 보내 알리는 방식의 이벤트 전달 인터페이스다. [추정][^ref-1025][^ref-1029]

## 설명

OpenAPI 3.1.0 은 API 가 받을 수 있는 수신 웹훅을 기술하는 필드를 두고, 로봇 운영 플랫폼 InOrbit 은 사고 관리용 외부 발신 웹훅을 제공한다고 적는다(벤더 주장).
