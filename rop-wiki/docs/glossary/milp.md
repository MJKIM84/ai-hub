# 혼합 정수 계획 (Mixed Integer Linear Programming (MILP))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 혼합 정수 계획 | Mixed Integer Linear Programming (MILP) | MILP — Mixed Integer Linear Programming |

## 한 줄 정의

일부 결정 변수가 정수여야 하는 선형 목적함수·선형 제약 최적화 문제로, 작업 배정·스케줄링 같은 조합 결정을 정식화해 해법기로 푸는 데 쓰인다. [추정][^ref-167]

## 설명

Peng 외는 LLM으로 자연어 작업 기술을 MILP 모델과 실행 코드로 바꿔 다중 로봇 배정·스케줄링을 푸는 틀을 제안했다.
