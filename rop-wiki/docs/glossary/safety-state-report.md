# 안전 상태 보고 (Safety State (VDA 5050 safetyState))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 안전 상태 보고 | Safety State (VDA 5050 safetyState) | VDA 5050 safetyState — Safety State |

## 한 줄 정의

VDA 5050 상태 메시지에서 로봇이 활성 비상정지의 종류(MANUAL·REMOTE·NONE)와 보호 필드 침범 여부(fieldViolation)를 관제에 알리는 항목이다. [추정][^ref-031]

## 설명

VDA 5050 3.0.0 기준이며 MANUAL 은 로봇에서 수동 확인, REMOTE 는 시설 비상정지를 원격 확인하는 경우다. VDA 5050 자체는 안전 표준이 아니다.
