# 웨이브리스 출고 지시 (Waveless Order Release)

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 웨이브리스 출고 지시 | Waveless Order Release | 없음 |

## 한 줄 정의

주문을 큰 묶음(웨이브)으로 모아 내리지 않고 도착·여유 용량에 따라 연속으로 현장에 내려보내는 출고 지시 방식이다. [추정][^ref-134]

## 설명

Gallien·Weber(2010)는 자동 분류기 창고에서 웨이브리스 정책이 가장 좋은 웨이브 정책 이상의 처리량을 더 낮은 교착 확률로 냈다고 보고했다. 출고 지시 방식은 상위 업무 시스템(WMS·WES)의 정책이며 ROP에는 입력 조건이다.
