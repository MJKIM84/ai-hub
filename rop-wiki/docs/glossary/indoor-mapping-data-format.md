# 실내 지도 데이터 형식 (Indoor Mapping Data Format (IMDF))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 실내 지도 데이터 형식 | Indoor Mapping Data Format (IMDF) | IMDF — Indoor Mapping Data Format |

## 한 줄 정의

Apple 이 개발해 OGC 커뮤니티 표준이 된 실내 지도 형식으로, 층·공간 단위·출입구·편의시설 등을 사람 길안내용으로 모델링한다. [추정][^ref-338]

## 설명

IMDF 1.0.0 은 2021-02-23 OGC 커뮤니티 표준이 되었으며 level·unit·opening·fixture·kiosk·amenity·anchor 지물을 둔다.
