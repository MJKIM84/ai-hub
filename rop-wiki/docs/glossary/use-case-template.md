# 사용 사례 템플릿 (Use Case Template (IEC 62559-2))

## 용어

| 한글 | 영문 | 약어와 풀어 쓴 이름 |
|---|---|---|
| 사용 사례 템플릿 | Use Case Template (IEC 62559-2) | IEC 62559-2 — Use Case Template |

## 한 줄 정의

IEC 62559-2가 정한 양식으로, 사용 사례·행위자 목록·요구사항 목록을 구조화해 기록하게 한다. [추정][^ref-1202]

## 설명

IEC 62559 사용 사례 방법론의 2부(2015)가 정한다. 템플릿의 세부 필드는 이번 조사에서 확인하지 못했다. 로봇 오케스트레이션에 적용한 사례는 확인되지 않았다.
