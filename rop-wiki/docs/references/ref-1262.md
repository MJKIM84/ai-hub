## 요약

산업용 로봇 시스템 진단 문제 2,500건 이상의 비공개 벤치마크 SYSDIAGBENCH 로 LLM 근본 원인 분석을 평가하고, QLoRA 미세조정 7B 모델이 GPT-4 보다 진단 정확도가 높았다고 보고. 초록만 확인.
