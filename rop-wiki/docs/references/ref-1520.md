## 요약

시행규칙 현행 통합본. 제7조의10 실외이동로봇 책임보험·공제 보험금 기준(사망·후유장애 1억5천만원, 부상 3천만원, 재물 사고당 10억원)과 2023-11-17 신설 표시. 같은 시행규칙 제7조의4·5 는 별도 id ref-1470 이다.

등록 실행: 2026-10-12-02 · 검증: 1차 조건부 승인 / 2차 통과
