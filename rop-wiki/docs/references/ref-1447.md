## 요약

SAP Warehouse Robotics(SAP BTP 기반, SAP EWM 과 구별)와 플릿 관리 시스템(FMS)을 잇는 폐기(Deprecated) 표시 API 문서. 요청→응답→콜백 순서, messageId, 취소 성공(CANCELLED)·취소 불가 통지 메서드를 정의한다. LATEST URL 이라 확보본(2024-07-10) 기준.

등록 실행: 2026-10-11-02 · 검증: 1차 조건부 승인 / 2차 통과
