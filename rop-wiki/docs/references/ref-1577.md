## 요약

Spot 이동 명령 정의. TerrainParams 의 ground_mu_hint 는 사용자가 주는 지면 마찰계수 힌트("Terrain coefficient of friction user hint")로 양수여야 하고 로봇이 범위를 제한할 수 있으며 주석상 권장 0.4~0.8, 기본 0.8 이다. StairsMode 는 계단 모드를 정하고 계단은 trot 보행에서만 지원되며, stairs_mode 를 정하지 않으면 예전 stair_hint 를 따른다. 계단 오류 시 자동 하강을 끄는 disable_stair_error_auto_descent 필드가 따로 있다. SDK 선언·주석이며 실제 미끄럼 제거나 안전을 보장하지 않는다.

등록: 현장 적용·운영 검증 조사(field-readiness-rop) · 원문 대조 검증 후 수동 게시
