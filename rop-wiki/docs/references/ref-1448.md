## 요약

Oracle WMS Cloud 26c 의 작업 우선순위 변경 API 문서(문서 ID G55063-04, Release 26C; 날짜는 페이지 메타데이터 dcterms.created). Ready·Held·Created 상태 작업만 변경할 수 있고 Task/Change task priority 권한이 필요하다.

등록 실행: 2026-10-11-02 · 검증: 1차 조건부 승인 / 2차 통과
