## 요약

IEEE 1872-2015 CORA 의 개념·관계만 분리한 수작업 OWL 번역(제3자). 로봇·로봇 시스템 분류와 robotPart·equippedWith(로봇 환경이 로봇 시스템을 갖춤)·자율성 수준 속성을 둔다. IEEE 표준 본문이 아니다.

등록 실행: 2026-09-25-23 · 검증: 1차 조건부 승인 / 2차 통과
