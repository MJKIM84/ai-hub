## 요약

DXF 도면을 SVG·PNG를 거쳐 AreaGraph로 분할해 osmAG(OSM XML)로 만드는 파이프라인의 공식 저장소 README. DWG 변환 조건과 도면 데이터 비공개를 밝힌다.

등록 실행: 2026-09-25-11 · 검증: 1차 조건부 승인 / 2차 통과
