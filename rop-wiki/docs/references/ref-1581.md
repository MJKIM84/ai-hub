## 요약

gRPC 공식 가이드의 기한(deadline) 설명. gRPC 는 기본 기한을 두지 않으며("gRPC does not set a deadline") 클라이언트·서버가 기한을 정하고 처리하는 방법을 다룬다. 언어별 구현 차이가 있다. RPC 기한 만료는 물리 작업이 수행되지 않았다는 증명이 아니다.

등록: 현장 적용·운영 검증 조사(field-readiness-rop) · 원문 대조 검증 후 수동 게시
