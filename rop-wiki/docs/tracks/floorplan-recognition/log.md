# 트랙 로그 — 건축 도면 자동 인식

이 로그는 중점 연구 트랙 [건축 도면 자동 인식](index.md)의 실행마다 무엇을 답했고, 어떤 질문이 새로 생겼고, [공간 그래프 스키마 초안](space-graph-schema-draft.md)가 어떻게 바뀌었고, 단계 완료 조건이 어떻게 평가됐는지를 기록한다. 갱신 주체는 퍼블리셔 스크립트다. 질문의 현재 상태는 [질문 백로그](question-backlog.md)에 있다.

## 항목 형식

실행마다 "실행 <실행 id> — 단계 <번호>. <이름>" 소제목 하나와 여덟 항목 표(실행 id, 단계, 답한 질문, 새 질문, 온톨로지 변경, 완료 조건 평가, 세부영역 반영 제안, 다음 실행 제안) 하나를 둔다. 항목의 뜻은 첫 트랙의 [트랙 로그](../manual-capability-ontology/log.md)와 같으며, "온톨로지 변경" 항목에는 이 트랙의 초안([공간 그래프 스키마 초안](space-graph-schema-draft.md))의 변경을 적는다. [가정] 항목은 최신순으로 쌓인다. "실행 기록" 절은 자동 갱신 영역(키 `track-log`)이며 원천은 `data/tracks/floorplan-recognition/log.json`이다.

이 페이지에는 사실 태그를 붙이지 않는다(운영 기록). [가정]
