# 질문 백로그

이 페이지는 중점 연구 트랙 [자연어 업무 지시 챗봇](index.md) 전용의 열린 질문 목록이다. 위키 전체의 [열린 질문](../../open-questions.md)에는 이 백로그로 가는 링크와 열린 질문 수만 둔다. 원천 데이터는 `data/tracks/nl-task-chatbot/backlog.json`이며, 아래 목록 표는 퍼블리셔가 그 파일에서 자동으로 만든다. 같은 목록이 [아이디어 2. 자연어 업무 지시 챗봇](../../ideas/nl-task-chatbot.md)의 "7. 미해결 질문 백로그"에도 상태순으로 실린다.

시드는 18개다. 사용자 요청의 시작 질문 3개(q1-01, q3-01, q4-01)는 문구 그대로 두고 알맞은 단계에 넣었고, 나머지는 구축자가 각 단계의 밝힐 것에서 정한 시작 질문이다. 제기 근거는 모두 `사용자`다(확장 아이디어 편입 요청). [가정]

## 항목 형식

항목 형식과 상태의 뜻은 첫 트랙의 [질문 백로그](../manual-capability-ontology/question-backlog.md)와 같다(사양서 8.2): id(`q<단계>-<두 자리>`, 한 번 부여한 id는 재사용하지 않는다), 질문, 단계(1~5), 제기 근거(finding id 또는 `사용자`), 상태(열림 / 조사 중 / 답함 / 보류 / 폐기), 답한 실행 id, 답이 실린 페이지 링크, 제기일. 트랙 실행마다 현재 단계의 열린 질문 가운데 사용자 지정 → 앞 단계로 되돌아온 질문 → 오래된 순으로 1~3개를 고른다.
