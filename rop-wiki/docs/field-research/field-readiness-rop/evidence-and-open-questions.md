# 근거와 남은 질문

<!-- auto:page-status:start -->
> 페이지 상태: published · 신뢰도: medium · 페이지 버전: 1 · 마지막 갱신: 2026-10-12 · 마지막 실행: 없음
<!-- auto:page-status:end -->

이 페이지는 이 분류 전체의 근거 장부다. 발표에서 나온 주장 가운데 공개 원문으로 확인된 것과 확인되지 않은 것, 외부 조사 결과를 원문과 다시 대조하며 고친 것, 앞으로 조사할 질문 15개를 모았다.

## 1. 현장 문제

발표 내용은 현장 경험이라 가치가 있지만, 날짜·수치·규정 해석이 기억이나 요약을 거치며 섞이기 쉽다. 예를 들어 "인수", "양산", "진입창은 모든 층" 같은 표현은 공개 원문과 대조하면 여러 사건이나 조건으로 나뉜다. 확인되지 않은 내용을 위키에 사실처럼 남기면 이후 연구가 그 위에 쌓인다.

## 2. 근거·적용 조건

아래 표는 발표 주장별 대조 결과다. "발표 기록" 열은 발표에서 그런 취지가 나왔다는 뜻이며 녹화·슬라이드로 교차 확인한 것이 아니다.

| 검증 대상 | 발표 기록 | 공개 원문 대조 | 판정 |
|---|---|---|---|
| 발표자·소속·행사일 | 발표자를 일반화. 정리 파일에 적힌 날짜가 있음 | 행사 프로그램·영상 원문 미확보 | 미확인. 실명 제외, 파일 날짜를 행사일로 쓰지 않음 |
| 로봇 회사 인수 시점 | 인수 연월 언급 | 2020-12-11 주요 조건 합의 공동 발표[^ref-1572], 2021-06-21 완료 발표[^ref-1573] | 합의와 완료를 나눠 표기 |
| 전동 휴머노이드 공개 | 최근 공개 연도 언급 | 전동 Atlas 소개 2024-04-17[^ref-1574], 제품 버전 공개 2026-01-05[^ref-1575] | 연구형 공개와 제품 버전 공개를 구분 |
| 양산·현장 투입 목표 | 연도 언급(전사 불확실) | 제품 버전 즉시 생산 개시·2026 물량 확정·추가 고객 2027년 초[^ref-1575], 2028 부품 서열 투입·2030 부품 조립 확대·2028년까지 연 3만 대 생산 체계 목표[^ref-1576] | 생산 개시·생산 능력·공정 투입을 하나의 "양산일"로 합치지 않음. 발표가 뜻한 연도는 미확인 |
| PTT 프로토콜 | 약어만 기록 | 철자·확장명·문서·판 미확보 | 미확인. 다른 표준으로 추측해 고치지 않음 |
| 계단은 항상 뒤로 내려간다 | 방향 설명 | 하강 방향 선호에 뒤로 선호·항상 뒤로·제약 없음이 있고, 값이 없으면 항상 뒤로, 제약 없음에 전진 하강 경고[^ref-1590] | 한 제조사 SDK의 하강 설정. 모든 계단·기종·상승으로 넓히지 않음 |
| 좁은 경로 엄격 추종의 폭 | 엄격 추종 설정 사용, 폭 값은 비공개 취급 | 엄격 추종 모드와 별도 필드인 회피 통로 폭의 절반(단위 미기재)이 있음[^ref-1590] | 발표의 폭 값·단위·기준 미확인, 재게시하지 않음 |
| 마찰 설정으로 기름 문제 해소 | 설정 조정과 청소 병행 | 사용자 마찰 힌트 필드(양수, 로봇이 제한 가능, 권장 0.4~0.8, 기본 0.8)[^ref-1577] | 필드 존재만 확인. 효과·안전·실측 마찰계수와의 관계는 미확인 |
| 조명을 끌 수 없다는 법적 설명 | 작업장 조명 제약 언급 | 상시 작업 장소의 작업면 조도 기준과 단서[^ref-1585] | 모든 공간 상시 점등 규정으로 옮길 근거 아님 |
| 진입창은 모든 층에 있다 | 소방 진입창 설명 | 11층 이하의 층, 특정 아파트 제외[^ref-1586], 2~11층 층마다 1개소 이상이되 지상 출입구가 있는 층 등은 설치하지 않을 수 있음[^ref-1587] | "모든 층"은 원문과 다름. 건축법령 계열로 확인할 사항 |
| 진입창을 가리면 안 되고 깨져도 파편이 없다 | 차광·유리 설명 | 표시·타격지점·크기·유리 종류와 두께, 삼중 유리의 비산방지필름 두께 조건[^ref-1587] | "일률 가림 금지", "파편 없음"은 원문에서 확인 못 함. 특정 차광안의 적법성 판정 아님 |
| 적용 현장·점검 항목 수·성능 | 다수 현장·점검 사례로 일반화 | 공개 시험 보고서·분모·기간 미확보 | 성과 수치로 쓰지 않음. 근거 미발견이 현장 부재는 아님 |
| 원격 조작·리셋과 자율 수행 | 영상·현장 개입 언급 | 제품이 자율·원격 조작·태블릿 조종을 구분[^ref-1575] | 특정 영상의 실제 모드·편집·성공률 미확인 |
| 관제·협업·완전 조율 | 발표의 성숙도 관점 | 공인 성숙도 표준으로 확인되지 않음 | 발표자 관점으로만 표시 |

## 3. ROP 판단

[의견] 이 분류의 내용은 근거 수준에 따라 위키 다른 곳에 반영할 수 있는 정도가 다르다.

| 종류 | 반영할 수 있는 형태 | 반영하지 않는 것 |
|---|---|---|
| 직접 연 공개 표준·공식 문서 | 판·절·접근일·원문 구절과 적용 한계 | 시험하지 않은 성능, 조건 밖 일반화 |
| 제조사 단독 문서 | "[추정] 벤더 주장:"으로, 문서가 말하는 지원·계획 | 독립 실증이나 안전 인증으로 승격 |
| 현행 법령 | 정확한 조문·시행일·적용 범위와 예외 | 특정 건물 설계 승인이나 법률 판단으로 확대 |
| 발표 관찰 | 일반화한 실패 유형과 조사 질문 | 원문, 실명, 현장명, 비공개 수치 |
| 미확인 전사 | 확인해야 할 질문과 필요한 원전 | 약어의 임의 복원, 양산 연도 추측 |
| 저장소 코드 관찰 | 기준 커밋·파일·함수·분기와 읽은 범위 | 실행 성공, 실기체 성능, 광학·전파 검증 |
| 이 조사의 제안 | "[의견]"인 수용 기준과 측정·비용 양식 | 공식 표준이나 인증 항목이라는 표시 |

## 4. 제조사·설비·운영자 역할

[의견] 미확인 항목은 대부분 원 자료를 가진 쪽만 닫을 수 있다. 발표 날짜·발표자·약어·수치는 발표 자료 소유자가, SDK 설정의 판별 의미는 제조사가, 특정 건물의 시설 변경 허용은 시설·법규 담당이, 현장 성과 수치는 운영자가 자료를 내야 확인된다. 공개 가능한 범위도 자료 소유자가 정한다.

## 5. 대응·판단 기준

**외부 조사 결과를 원문과 대조하며 고친 것.** 이 분류의 페이지는 고친 내용으로 썼다.

- 발행일: CES 로봇 전략 발표는 본문 날짜 2026-01-05(사이트 게시 2026-01-06 KST)[^ref-1576], NIST 시험 방법 페이지는 작성 2014-04-28·갱신 2026-04-24[^ref-1580], W3C SSN은 2017-10-19 권고안(2017-12-08 링크 오류 수정)[^ref-030]으로 확인했다.
- 인수 조건 합의 발표는 한쪽 회사 단독이 아니라 거래 당사자 공동 보도자료였다.[^ref-1572]
- 진입창 조문: 시행령의 아파트 예외는 아파트 전체가 아니라 대피공간 등을 설치한 아파트와 비상용승강기를 설치한 아파트 두 종류다.[^ref-1586] 규칙의 층 예외는 의무 면제가 아니라 "설치하지 않을 수 있다"는 재량 문구이며, 삼중 유리 조건은 구성 유리의 종류·두께와 필름 두께(50마이크로미터 이하)까지 정한다.[^ref-1587]
- 스트리밍 전달 의미: 외부 시스템까지의 exactly-once는 "일반적으로" 그 시스템의 협조가 필요하다는 문장이다.[^ref-1582]
- 절 이름: 열화상 문서의 해당 절은 "Measurement parameters > Types of parameters"[^ref-1589], 다중 로봇 시뮬레이션 문서는 "Plugins > Robots"(slotcar)[^ref-406]다.
- VDA 5050의 범위 밖 항목은 안전 요구·교통 관리 논리·주변 설비와 외부 IT 인터페이스·프로젝트 조정과 구현 절차·운영 책임 할당·사이버보안이다.[^ref-031]
- 시뮬레이터 코드 범위: 마찰 설정은 `_build` 78~241행과 `_research_robot` 247~297행에 걸쳐 있다.
- 열린 질문 연결: 설비 상태 신선도는 oq-032가 아니라 oq-034, 통신 허용 지연은 oq-208이 아니라 oq-039, 순차 배포는 oq-213이 맞는 질문이다. oq-028(위치 신뢰도), oq-063(도킹 정밀도와 파지), oq-067(승강기 공유 배분)을 더했다.

## 6. 검증·한계

- 공개 출처 23개는 원문을 다시 열어 인용 구절·판·발행일을 대조했다. 투명 물체 논문(S21)은 저자 초록만 읽었다.
- GitHub에 있는 SDK·명세는 master·main 판이다. 특정 릴리스·현장 펌웨어에 그대로 적용되는지는 알 수 없다.
- 법령은 열람한 날의 현행 조문이다. 이후 개정될 수 있고, 특정 건물에는 허가 시점의 규정이 적용될 수 있다.
- 기존 위키의 참고문헌 가운데 원문 미열람으로 표시된 것(예: ref-041)은 이번 조사에서도 원문을 열지 못해 새 사실의 근거로 쓰지 않았다.
