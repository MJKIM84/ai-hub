# 학습 순서

<!-- auto:page-status:start -->
> 페이지 상태: published · 신뢰도: medium · 페이지 버전: 1 · 마지막 갱신: 2026-10-12 · 마지막 실행: 없음
<!-- auto:page-status:end -->

주어진 시간에 따라 세 가지 계획을 둔다. 모두 [의견]이다. 자료 번호 S01~S18은 [핵심 학습 자료](core-materials.md)의 카드를 가리킨다. 어느 계획이든 원문 18개를 전부 정독하는 것이 아니라 **지정한 절을 읽고 결정해야 할 질문을 얻는 것**이 목표다.

## 2시간: 전체 구조 이해

| 분량 | 읽을 자료·절 | 해야 할 작업 | 이해 확인 질문 |
|---|---|---|---|
| 0~20분 | S01·S02 제품 사양과 구성, S03 Arm 질량 | 기본 기능·추가 장비·미확인의 세 열 작성 | 이 로봇이 기본 구성으로 물건을 집거나 문을 여는가? |
| 20~40분 | S05 1784, S06 BMW의 점검 문단 | 배송·순찰·안내의 완료 조건을 한 줄씩 | 도착과 유효한 서비스 완료를 구분할 수 있는가? |
| 40~70분 | S07 Full Control, S08 설비 연동, S09 범위 | 서비스 → ROP → 어댑터 → 로봇·설비를 그림으로 | 누가 주행하고 누가 승강기를 제어하는가? |
| 70~90분 | S04 GraphNav 피드백, S10 QoS 요약 | 응답 유실·위치 상실·취소의 차이 정리 | 다른 로봇에 재배정하기 전에 무엇을 확인하는가? |
| 90~110분 | S11 변수 통제, S14 제25조의2 | 현장 조사·촬영 확인 질문 5개 | 공개 로비의 카메라를 그냥 켜도 된다고 말하지 않는가? |
| 110~120분 | [개요](index.md)의 결정표 | 우선 서비스 하나, 기종 가설, 미확인 3개 작성 | 근거와 자신의 제안을 구분해서 말하는가? |

산출물은 **1페이지 결정 메모**다. 고객·문제·완료·KPI·기종 가설·시설 조건·실패 대안·추가 확인을 각 1~2줄로 쓴다.

## 1일: 제안의 근거 확보

학습과 작성 합계 **8시간(480분)**, 휴식은 별도다. 실제 현장 측정 시간은 포함하지 않는다.

| 시간 | 자료와 작업 | 당일 산출물 |
|---|---|---|
| 60분 | S01~S04와 보조 연습(Clearpath). 제품 구성·판·추가 기능 확인 | 기종 비교표와 공급사 질문 5개 |
| 75분 | S05·S06·S17. 세 서비스의 흐름과 이용자·관리자 요구 작성 | 정상·예외 흐름, 권한·화면·상태 목록 |
| 90분 | S07~S10. 업무 하나의 연동을 끝까지 추적 | 책임 구성도, 시퀀스, 요청·취소·완료 계약 |
| 90분 | S11~S13. 환경 → 실패 → 시험의 연결 | 현장 조사표, RACI, 우선 시험 8개(T03·T04·T05·T07·T08·T09·T11·T12) |
| 60분 | S14~S16과 국내법 보조 조문 | 영상·시설·안전 적용 범위와 전문 검토 목록 |
| 60분 | 사업 모델·가상 ROI 템플릿을 실제 견적 질문으로 전환 | 비용 변수, 현금화, 민감도, 공개 근거 없는 숫자 목록 |
| 45분 | 발표 조합 선택과 반론 점검 | 발표 개요와 각 장의 출처·검증 질문 |

완료 기준: 핵심 문장마다 출처 또는 **가정·제안·미확인** 표시가 붙고, 도입 효과가 나쁘게 나오는 경우에도 계산이 성립해야 한다.

## 1주: 사례·설계·시험 심화

예시는 **하루 3시간, 총 21시간**이다. 문서 읽기, 인터뷰 준비, 모의 검토가 중심이다. 현장 운전은 별도로 승인된 전문팀의 일정이다.

| 일차 | 학습·검토 | 누적 결과와 완료 질문 |
|---|---|---|
| 1일 | S01~S04 기체·구성, 최신 견적·매뉴얼 요청 목록 | 능력 선언 대 현장 승인 표. 사양 상충을 모두 기록했는가? |
| 2일 | S05·S06·S17 서비스와 고객 가치, 현행 프로세스 인터뷰 질문 | 고객·운영자 여정, 인계·점검 품질, 접근성. 로봇 없이 해결하는 대안도 있는가? |
| 3일 | S07~S10 연동 계약과 장애 타임라인 | API·상태표·시설 세션. 취소·중복·단절 뒤에도 원장이 일관적인가? |
| 4일 | S11~S13·S18 측정·안전·시험, 사진·도면 기반 책상 검토 | 조사표와 14개 시험의 현장별 조건. V·N·T·E를 구분했는가? |
| 5일 | S14~S16·국내법 보조, RACI·운영 이관·사고 흐름 | 실제 법적 주체, 출동·재개 권한, 영상 처리 흐름. 책임 공백은 없는가? |
| 6일 | 견적 비교, 수요·개입·현금화 민감도, 시범 설계 | 사업 모델과 확대·중단 기준. 사람 대체 비용과 이종 운영비를 빠뜨리지 않았는가? |
| 7일 | 반론 질문 10개, 출처 재확인, 발표 리허설 | 최종 근거 패키지. 미확인 내용을 사실처럼 말하는 문장을 지웠는가? |

V·N·T·E는 [현장 구축과 인수시험](deployment-and-acceptance.md)의 수치 기준 구분(제조사 제한·법 의무·고객 목표·안전 설계 한계)이다.

## 근거 카드

자료를 읽을 때마다 아래 카드를 한 장씩 쓴다. 카드가 쌓이면 발표의 각 장에 붙일 출처와 반론 대비가 된다.

```text
결정할 질문:
핵심 주장과 유형(제조사 / 운영기관 / 연구 / 표준·법 / 제안):
출처 URL / 발행·개정일 / 제품·문서 판 / 관련 절:
직접 확인한 내용 / 짧은 구절:
그 자료가 입증하지 않는 것:
우리 건물·적재·센서·업무와 다른 조건:
PM 선택지와 비용·운영 영향:
추가 확인 담당자 / 필요한 증거 / 결정 기한:
```
